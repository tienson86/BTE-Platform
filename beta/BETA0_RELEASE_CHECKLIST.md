Tests PASS does not check these boxes.

---

## Before every Beta release

- [ ] Golden Dataset regenerated
- [ ] Executive PDFs regenerated
- [ ] Professional PDFs regenerated
- [ ] No engine language
- [ ] No glossary dump
- [ ] No duplicate recommendations
- [ ] No broken fragments
- [ ] Editorial review PASS
- [ ] Commercial review PASS
- [ ] Product Owner approval

---

## How to apply

| Item | Evidence |
|------|----------|
| Golden Dataset regenerated | Fresh production PDFs for frozen cases in `BETA0_GOLDEN_DATASET.md` |
| Executive PDFs regenerated | Anchor cases Sơn · Huỳnh · Tân at minimum |
| Professional PDFs regenerated | Same anchors, Professional edition |
| No engine language | Editorial review of customer prose |
| No glossary dump | Consultation editions contain no encyclopedia dump |
| No duplicate recommendations | Cross-page and ranked-rec review |
| No broken fragments | PDF/HTML product read |
| Editorial review PASS | Chief Editor / ES-V1 scorecards |
| Commercial review PASS | Commercial acceptance of the artifacts |
| Product Owner approval | Signed `BETA0_SIGNOFF.md` for that release |

---

## Fail closed

If any box is unchecked, the release does not ship.

Do not substitute:

- a Completion Report
- a test summary
- a verbal “looks good”

---

## Official status

**This checklist is mandatory for every Beta release.**
