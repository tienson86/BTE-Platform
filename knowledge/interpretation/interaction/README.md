## The question this package answers

What information must exist **before Narrative** can truthfully explain the **current life period**?

Answer: **Interaction Truth** — structured facts about the relation between already-published **Natal Truth** and already-published **Current Da Yun / Current Luck Facts**.

Without those facts, Narrative can only repeat natal truth under a decade label.

Natal engines own natal values.
