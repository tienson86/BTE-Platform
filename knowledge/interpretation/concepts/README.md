# BaZi Concept Layer (K1.5)

Reusable semantic knowledge graph between Decision Explanation and Knowledge Entities.

## Flow

```text
Decision Explanation → Concept Layer → Knowledge Entities → Narrative
```

Concepts hold reusable expert meaning. Knowledge entities reference concepts via `concept_ids` — they do not duplicate concept content.

## Categories

| Category | Purpose |
|---|---|
| `core` | Structural BaZi semantics (strength, balance, element dynamics) |
| `symbolic` | Stem/branch symbolic archetypes |
| `application` | Life-domain application patterns |
