Canonical source of truth for BTE-Platform number-energy interpretation.

Version: `1.0`
Status: `FROZEN`
Domain: `Bát Cực Linh Số / Năng lượng số`
Primary use cases: phone numbers, car plates, motorbike plates, identity numbers, account numbers, house numbers.

---

## 1. Scope And Freeze Principles

This file is the canonical knowledge base for the BTE-Platform module `number_energy`.

Cursor and all downstream agents MUST treat this file as the source of truth for:

- digit-to-gua mapping;
- digit-to-element mapping;
- East/West house grouping;
- trigram line-difference rules;
- the 8 Du Niên energy fields;
- strength order of pair groups;
- customer-facing interpretation boundaries;
- special handling of digits `0` and `5`;
- primary control/remedy relations.

Cursor MUST NOT:

- infer new meanings outside this file;
- add new pair groups without explicit human approval;
- turn health indications into medical diagnosis;
- treat `0` or `5` as ordinary gua numbers;
- score energies numerically unless a later frozen scoring file defines it;
- override this file using internet sources, generic feng shui sources, or model memory.

If a requested interpretation cannot be derived from this file or from an explicitly frozen later version, the engine MUST return an `UNKNOWN_OR_NOT_DEFINED` state instead of inventing a rule.

This system should be described to customers as a Bát Cực Linh Số methodology, also displayed as `Năng lượng số`. It should not be presented as a medically, scientifically, or universally verified law.

Đông tứ:

- `1` Khảm;
- `3` Chấn;
- `4` Tốn;
- `9` Ly.

Tây tứ:

- `2` Khôn;
- `6` Càn;
- `7` Đoài;
- `8` Cấn.

Central modifiers:

- `0` Âm trường;
- `5` Dương trường.

`0` and `5` do not belong to Đông tứ or Tây tứ for pair-energy generation.

## 4. Trigram Line Model

The engine stores the 8 ordinary gua with the following frozen line vectors.

Important implementation note: for this BTE number-energy engine, the three-bit vector order is:

```text
[Địa, Nhân, Thiên]
```

This order is intentionally frozen because it reproduces the approved pair tables below. Do not rename or reorder these positions without a versioned migration.

| Digit | Gua | Vector `[Địa, Nhân, Thiên]` |
|---|---|---|
| `6` | Càn | `111` |
| `7` | Đoài | `110` |
| `9` | Ly | `101` |
| `3` | Chấn | `100` |
| `4` | Tốn | `011` |
| `1` | Khảm | `010` |
| `8` | Cấn | `001` |
| `2` | Khôn | `000` |

## 5. Tam Hào Difference Rules And 8 Du Niên

Given two ordinary gua digits, compare their frozen vectors position by position.

| Changed Lines | Du Niên | Energy ID | Classification | Star | Element |
|---|---|---|---|---|---|
| none | Phục Vị | `fu_wei` | supportive / stabilizing | Tả Phù | None |
| Thiên only | Sinh Khí | `sheng_qi` | supportive | Tham Lang | Mộc |
| Nhân only | Tuyệt Mệnh | `jue_ming` | challenging | Phá Quân | Kim |
| Địa only | Họa Hại | `huo_hai` | challenging | Lộc Tồn | Thổ |
| Thiên + Nhân | Ngũ Quỷ | `wu_gui` | challenging | Liêm Trinh | Hỏa |
| Nhân + Địa | Thiên Y | `tian_yi` | supportive | Cự Môn | Thổ |
| Thiên + Địa | Lục Sát | `liu_sha` | challenging | Văn Khúc | Thủy |
| Thiên + Nhân + Địa | Diên Niên | `yan_nian` | supportive | Vũ Khúc | Kim |

These rules are equivalent to the frozen khẩu quyết:

- thượng nhất biến: Sinh Khí;
- trung hào biến: Tuyệt Mệnh;
- hạ nhất biến: Họa Hại;
- thượng nhị biến: Ngũ Quỷ;
- hạ nhị biến: Thiên Y;
- thượng hạ giai biến: Lục Sát;
- tam hào giai biến: Diên Niên;
- tam hào bất biến: Phục Vị.

The engine MUST prefer the line-difference rule as the source of derivation, then validate against the frozen pair table in section 6.

## 8. Special Digit Rules For 0 And 5

Digits `0` and `5` are modifiers, not ordinary gua digits.

They MUST NOT be processed as normal pair digits in the 8 Du Niên pair table.

### 8.1 Digit 0

```yaml
digit: 0
type: yin_modifier
normal_pair_energy: false
effect_keywords: [hidden, attenuating, concealing, suppressing]
canonical_state: HIDDEN
```

`0` hides, attenuates, conceals, or suppresses the underlying pair-energy when it stands between two ordinary gua digits.

Example:

```text
103
underlying_pair: 13
underlying_energy: Thiên Y
state: HIDDEN
interpretation: Thiên Y vẫn là năng lượng gốc, nhưng bị âm trường che hoặc giảm biểu hiện.
```

### 8.2 Digit 5

```yaml
digit: 5
type: yang_modifier
normal_pair_energy: false
effect_keywords: [reveal, activate, amplify]
canonical_state: AMPLIFIED
```

`5` reveals, activates, or amplifies the underlying pair-energy when it stands between two ordinary gua digits.

Example:

```text
153
underlying_pair: 13
underlying_energy: Thiên Y
state: AMPLIFIED
interpretation: Thiên Y là năng lượng gốc và được dương trường kích hoạt/khuếch đại.
```

## 9. Canonical Energy States

The engine may assign the following states to an energy occurrence:

| State | Meaning |
|---|---|
| `NORMAL` | Energy appears through an adjacent ordinary pair with no modifier or special interaction. |
| `HIDDEN` | Energy is present as an underlying pair but hidden or attenuated by `0`. |
| `AMPLIFIED` | Energy is activated or strengthened by `5` or by supported repetition. |
| `REPEATED` | Same energy appears repeatedly in close sequence. |
| `CONTROLLED` | A challenging energy is checked by its proper controlling supportive energy. |
| `NEUTRALIZED` | A challenging energy is sufficiently balanced by an approved remedy structure. Use only when the interaction rules explicitly allow it. |

In V1, `CONTROLLED` and `NEUTRALIZED` are not interchangeable.

## 11. Customer-Facing Health Rule

Health language MUST be framed as symbolic or methodological, for example:

```text
Theo hệ thống Bát Cực Linh Số, trường khí này gợi ý nên lưu ý...
```

Customer-facing output MUST NOT:

- diagnose a disease;
- predict illness as certainty;
- replace medical advice;
- instruct the customer to start, stop, or change treatment;
- claim that a phone number or plate number causes disease.

If health is mentioned, add a gentle disclaimer when appropriate:

```text
Phần này chỉ mang ý nghĩa tham khảo theo hệ thống Năng lượng số, không phải chẩn đoán y khoa.
```
