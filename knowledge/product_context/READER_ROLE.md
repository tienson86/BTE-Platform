# READER_ROLE

| Role | Meaning |
|------|---------|
| SELF | Subject reads for themselves |
| PARENT | Adult caregiver reads about a dependent |
| SPOUSE | Partner lens (reserved) |
| CONSULTANT | Practitioner lens |
| UNKNOWN | Unspecified — CHILD defaults to PARENT |

Determines who the report is speaking to (voice + action addressee), not BaZi facts.
