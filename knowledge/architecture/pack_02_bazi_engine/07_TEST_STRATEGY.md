# 1. Purpose

This document defines the official testing strategy for the BaZi Engine.

The objective is to verify that every canonical BaziChart generated by the engine is:

- Structurally correct
- Academically correct
- Deterministic
- Complete
- Backward compatible
- Ready for downstream analysis

No release may proceed without passing all mandatory test levels.

---

# 2. Testing Philosophy

The BaZi Engine produces structural facts.

Testing focuses on validating those facts.

The engine never produces opinions or interpretations.

Every identical BirthContext must always generate the same BaziChart.
