# 1. Purpose

This document defines the canonical testing strategy for the Interpretation Engine.

The objective is to verify that every InterpretationResult generated by the Engine is

- Correct
- Deterministic
- Readable
- Explainable
- Traceable
- Localizable
- Ready for Report Engine

The Interpretation Engine validates narrative generation rather than analytical reasoning.

---

# 2. Testing Philosophy

The Interpretation Engine never evaluates BaZi knowledge.

Its responsibility is to transform a validated AnalysisResult into a validated InterpretationResult.

Testing therefore verifies

- Narrative generation
- Sentence selection
- Template selection
- Placeholder resolution
- Explanation generation
- Narrative integrity
- Localization
- Traceability

Every identical AnalysisResult must always produce an identical InterpretationResult.
