# 1. Purpose

This document defines the canonical testing strategy for the Score Engine.

The objective is to verify that every analytical conclusion generated by the Score Engine is

- Correct
- Deterministic
- Explainable
- Traceable
- Academically consistent
- Ready for Interpretation Engine

The Score Engine has the highest testing requirements within the BTE Platform.

---

# 2. Testing Philosophy

The Score Engine does not simply calculate scores.

It performs analytical reasoning.

Therefore testing verifies

- Rule execution
- Evidence generation
- Conflict resolution
- Priority resolution
- Score calculation
- Confidence calculation
- AnalysisResult construction

Every identical BaziChart must always produce an identical AnalysisResult.
