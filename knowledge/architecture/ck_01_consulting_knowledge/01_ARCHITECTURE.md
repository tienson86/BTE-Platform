# 01 — Architecture

| Field | Value |
|-------|--------|
| Document | CK-01A Consulting Knowledge Architecture |
| Version | 1.0.0 |
| Status | Canonical for CK-01A |

---

## 1. Purpose

Transform published analytical truth into consulting knowledge.

Knowledge does not discover truth. It matches consulting meaning onto truth that already exists.

---

## 2. Position

```
Calendar / BaZi / Strength / Pattern / Useful God / Luck
        ↓
Canonical Analysis Result (facts, frozen)
        ↓
Identity (frozen)
        ↓
Integrated Narrative (frozen)
        ↓
Consulting Knowledge Platform (CK-01)   ← this epic
        ↓
Consulting Knowledge Units
        ↓
(later, only after freeze) consulting consumers
```

---

## 3. What this platform is

A deterministic consulting knowledge base.

| Is | Is not |
|----|--------|
| Knowledge catalog | Analytical engine |
| Condition matcher | Calculator |
| Consulting wording store | LLM |
| Action library | Report / PDF / DOCX renderer |

---

## 4. Inputs (read-only)

| Input | Use |
|-------|-----|
| Integrated Narrative | Published customer speech and topic findings |
| Identity | Published person / pillar / interpretation keys |
| Canonical Analysis Result | Published engine fields |

Knowledge may copy published signals. It may not recompute them.

---

## 5. Output

`ConsultingKnowledgePack` of `ConsultingKnowledgeUnit` records.

If nothing matches, the pack is insufficient. Empty copy: `Chưa có dữ liệu`.

Do not invent a consulting reading to fill the gap.

---

## 6. Forbidden

- calculate, predict, infer unpublished facts
- call Calendar, Bazi, Strength, Pattern, Useful God, Luck
- rewrite Integrated Narrative or Identity
- generate wording with an LLM
- render Report / PDF / DOCX

---

END
