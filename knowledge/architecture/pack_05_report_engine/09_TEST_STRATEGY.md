# 1. Purpose

This document defines the canonical testing strategy for the Report Engine.

The objective is to verify that every ReportResult generated by the Engine is

- Correct
- Deterministic
- Renderable
- Exportable
- Responsive
- Accessible
- Traceable
- Ready for production

The Report Engine validates presentation quality rather than analytical correctness.

---

# 2. Testing Philosophy

The Report Engine never evaluates

- Calendar calculations
- BaZi structures
- Analysis logic
- Interpretation logic

Those responsibilities belong to upstream Engines.

The Report Engine verifies

- Layout
- Theme
- Rendering
- Export
- Presentation
- Accessibility
- Performance

Every identical InterpretationResult must always produce an identical ReportResult.
