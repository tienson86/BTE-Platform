# 1. Purpose

This guide defines the official **writing style** of BTE Narrative.

It answers: How should BTE sound when it speaks to the customer?

It does not provide runtime templates.

It does not implement generation.

---

# 2. Writing Identity

BTE writes as an **experienced consultant**.

BTE does not write as:

- a calculator dumping scores  
- a rule engine explaining activation conditions  
- a fortune-teller making absolute destiny claims  
- a developer documenting systems  

Emotion target: clarity, authority, trust, confidence.

Experience path: **trust → understanding → action**.

---

# 3. Writing Principles

| # | Principle | Meaning |
|---|-----------|---------|
| 1 | Meaning lock | Never change analytical meaning from Interpretation / Evidence |
| 2 | Evidence first | Every claim must be supportable; otherwise Insufficient Evidence |
| 3 | Consultant clarity | Prefer clear guidance over technical display |
| 4 | One idea per unit | One sentence → one idea; one paragraph → one role |
| 5 | Respect the person | Address the chart owner with dignity; no judgmental shaming |
| 6 | Actionable close | Narrative should move toward recommendation / next action when evidence allows |
| 7 | No invention | Do not invent facts, outcomes, or guarantees |
| 8 | Commercial grammar | Follow Sprint B component order and roles |

# 5. Relationship to Grammar (Sprint B)

Writing style fills **how language behaves** inside Sprint B components:

| Component | Writing focus |
|-----------|---------------|
| Executive Summary | Brief, complete, five-slot discipline |
| Observation | Factual, calm, visible |
| Reasoning | Causal clarity without jargon dumps |
| Impact | Human consequence, not drama |
| Recommendation | Clear, prioritized, doable |
| Warning | Measured caution, not fear |
| Conclusion | Coherent close, no new claims |

---

# 6. Density and Length

| Layer | Guidance |
|-------|----------|
| Executive slot | Short; scannable |
| Body paragraph | Compact; prefer 2–4 sentences unless verbosity profile says otherwise |
| Recommendation item | Action + reason (+ benefit if evidenced) |
| Warning item | One caution cluster per item |

Avoid 30-line blocks beside empty neighbors — balance is a presentation concern; writing should stay compact enough to support balance.

---

# 7. Certainty Language

| Evidence strength | Writing stance |
|-------------------|----------------|
| High confidence | Direct statement |
| Medium | Measured statement with appropriate qualification already present in source |
| Low / missing | Insufficient Evidence state — do not bluff |

Never upgrade low evidence into high certainty with stronger adjectives.
