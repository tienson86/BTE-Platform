# 1. Purpose

This document defines **sentence-level structure** for BTE Narrative writing.

It specifies form rules.

It does not supply runtime templates or generated sentence banks.

---

# 2. Core Sentence Rule

**One sentence → one idea.**

If a sentence carries observation + reason + action, split it across components or into multiple sentences with single roles.

---

# 3. Preferred Sentence Shapes

| Shape | Use | Typical component |
|-------|-----|-------------------|
| Subject + observation | State what is seen | Observation |
| Observation + because/link | Explain why | Reasoning |
| Observation + consequence | State meaning | Impact |
| Imperative / guided action | Advise | Recommendation |
| Caution frame + risk | Warn | Warning |
| Synthesis statement | Close | Conclusion / Executive |

Links must come from validated Interpretation — not newly invented causality.

---

# 4. Length

| Guidance | Rule |
|----------|------|
| Prefer | Short to medium sentences |
| Avoid | Long chains with many subordinate clauses |
| Limit | Generally one main clause; at most one subordinate clause unless clarity requires more |

---

# 5. Voice and Grammar Preferences

| Prefer | Avoid |
|--------|-------|
| Active voice when speaking to the person | Passive hiding agency for no reason |
| Concrete nouns from evidence | Abstract filler with no referent |
| Clear verbs | Stacked nominalizations that obscure action |
| Plain connectors | Pseudo-classical ornament with no meaning |

---

# 6. Sentence Roles (Align to Sprint B)

| Role | Allowed in | Forbidden in |
|------|------------|--------------|
| Observation | Observation, Executive identity | Recommendation-as-only-content |
| Explanation | Reasoning | Warning-only blocks as fake reasoning |
| Impact | Impact | Observation-only sections |
| Suggestion / action | Recommendation, Executive action slots | Observation / Reasoning |
| Caution | Warning, Executive weakness slot | Recommendation primary action text |
| Summary | Conclusion, Executive | Mid-flow as a place to sneak new claims |

---

# 7. Qualification and Modality

| Pattern | When allowed |
|---------|--------------|
| Direct indicative | Evidence supports direct claim |
| Softener already in source | Only if Interpretation/Evidence includes that stance |
| Absolute destiny modality | Forbidden |
| Invented probability (“80% chắc chắn”) | Forbidden unless explicitly present as approved source wording |

---

# 8. Lists vs Sentences

| Form | When |
|------|------|
| Full sentences | Default for Observation / Reasoning / Impact / Conclusion |
| Compact list items | Executive strengths/weaknesses; Recommendation / Warning item heads |
| Bare score dumps | Forbidden as a substitute for sentences |

---

# 9. Insufficient Evidence Sentences

When state is Insufficient Evidence:

- Do not write speculative filler sentences  
- Use the platform insufficient-data outcome for that slot/component  
- Do not soften invention into “có thể là…” without evidence  

---

# 10. Anti-patterns (Sentence)

✗ Multi-role mega-sentences  
✗ Rule-activation syntax in customer sentences  
✗ English fragment labels inside Vietnamese narrative body  
✗ Rhetorical questions as a habit (occasional OK; not default)  
✗ Sentence that introduces a new analytical fact
