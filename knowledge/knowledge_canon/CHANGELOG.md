# Purpose

This document records all significant changes made to the Knowledge Canon framework.

Its purpose is to provide historical transparency, version traceability, and governance support throughout the lifecycle of the Knowledge Canon.

---

# Versioning Policy

The Knowledge Canon follows Semantic Versioning (SemVer):

```
MAJOR.MINOR.PATCH
```

| Type | Description |
|------|-------------|
| MAJOR | Breaking architectural changes |
| MINOR | New capabilities or backward-compatible enhancements |
| PATCH | Documentation corrections, metadata updates, typo fixes |

---

# Change Categories

Every change shall be classified into one of the following categories:

| Category | Description |
|----------|-------------|
| Added | New functionality or documentation |
| Changed | Modification of existing content |
| Deprecated | Scheduled for removal |
| Removed | Permanently removed |
| Fixed | Corrections |
| Security | Security or governance related updates |

---

# Backward Compatibility

Minor and Patch releases shall maintain backward compatibility.

Breaking changes require a new MAJOR version.

---

# Deprecation Policy

Deprecated content shall:

- remain documented;
- include replacement guidance where applicable;
- specify the target removal version.

Deprecated items shall not be removed immediately.

---

# Migration Policy

Whenever breaking changes occur, migration guidance shall include:

- affected modules;
- required updates;
- compatibility considerations;
- transition timeline.

---

# Audit Requirements

Every release shall preserve:

- Version number
- Release date
- Reviewer
- Governance approval
- Change rationale

Historical records shall never be deleted.

---

# Governance

Only authorized maintainers may publish new releases.

All releases require governance approval.
