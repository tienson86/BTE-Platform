# Knowledge Canon

> **BTE Platform — Knowledge Canon V1.0**

---

# Overview

The Knowledge Canon is the central knowledge repository of the BTE Platform.

It serves as the Single Source of Truth (SSOT) for all structured domain knowledge used throughout the system.

Unlike the Reference Library, which preserves authoritative source materials, the Knowledge Canon contains normalized, version-controlled, machine-readable knowledge assets derived from those references.

Every rule, sentence, interpretation, score, report, and explanation generated by the platform must ultimately trace back to one or more Knowledge Assets contained in this module.

---

# Purpose

The Knowledge Canon exists to:

- Standardize domain knowledge.
- Normalize concepts across multiple classical references.
- Remove duplicated knowledge.
- Preserve source traceability.
- Support rule generation.
- Support sentence generation.
- Support explainable AI.
- Enable long-term governance.

# Core Principles

## 1. Single Source of Truth

Every concept shall exist only once.

---

## 2. Reference Driven

Every Knowledge Asset must cite at least one authoritative reference.

---

## 3. Atomic Knowledge

Each Knowledge Asset represents exactly one concept.

---

## 4. Explainability

Every interpretation must be explainable through traceability.

---

## 5. Version Controlled

Knowledge is immutable by version.

Updates create new versions.

---

## 6. Machine Readable

Knowledge must be consumable by engines without manual interpretation.

---

# Knowledge Asset

A Knowledge Asset is the smallest reusable unit of knowledge.

Example

```
Giáp Mộc

Definition

Nature

Characteristics

Relationships

Evidence

References

Rules

Terminology

Confidence
```

Knowledge Assets are not documents.

They are normalized knowledge objects.
