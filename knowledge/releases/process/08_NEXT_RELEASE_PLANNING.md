---

## 1. Purpose

Define planning rules for the sequence:

```
Commercial V1
    ↓
Commercial V1.1
    ↓
Commercial V2
```

---

## 2. Sequence meaning

| Version | Intent (planning default) |
|---------|---------------------------|
| **Commercial V1** | First commercial Result experience with Career Selection + Promotion Readiness; architecture frozen |
| **Commercial V1.1** | Incremental Capability and/or quality train without architecture era change |
| **Commercial V2** | Next commercial era — larger Capability set and/or intentional architecture/product step-up |

Exact scope of V1.1 / V2 is set by Product Roadmap + Capability Registry — this file sets **rules**, not the feature list.

---

## 3. Planning rules

1. **Close the current RC before opening the next Commercial train as a substitute.**  
   - Do not start V1.1 Development to avoid finishing Commercial V1 Human Review.  

2. **Capability Roadmap is the backlog source.**  
   - e.g. Leadership Assessment is a candidate for V1.1+ — not automatic.  

3. **Architecture freeze wins.**  
   - V1.1 should not require Foundation redesign.  
   - V2 may propose architecture changes only via explicit freeze review.  

4. **One primary Commercial train at a time** for announcement.  
   - Parallel Capability authoring is allowed; announcement trains stay ordered.  

5. **Every train repeats the Release Workflow.**  
   - Development → RC → Human Review → Release → Maintenance → Next.  

6. **Gates are not optional for later versions.**  
   - V1.1 / V2 still require all five Release Gates.  

7. **Post-release expansion enters the next planned train** unless Hotfix-eligible.  

8. **Registry and Changelog must stay truthful** before marketing language changes.

---

## 4. Entry criteria for V1.1 planning

- Commercial V1 Product decision is **GO** or **GO WITH MINOR FIXES**, **or** Product explicitly parks V1 and re-scopes (written).  
- V1 open Blockers closed or accepted.  
- Candidate Capabilities Proposed/Planned in Registry.  
- Capacity for Golden Cases + Human Review reserved.

---

## 5. Entry criteria for V2 planning

- At least one successful Commercial release cycle completed (or Product architecture mandate).  
- Clear customer outcome delta vs V1/V1.1.  
- Architecture impact assessment complete.  
- Multi-Capability acceptance plan funded.

Next-version planning follows this policy. Wait for Product Review on Commercial V1 RC1 before committing V1.1 scope.
