# Reasoning Philosophy

Reasoning makes Strength (and every later package) **replayable**.

A conclusion such as “thân vượng” is not a score dump. It is a path: what was observed, which evidence applied, which rules fired, what intermediate tendency formed, and which final band was chosen — plus which alternatives were considered and which contradictions remain open.

Reasoning never invents rules. It only arranges existing Knowledge + Evidence into a deterministic graph.
