# Pattern Knowledge Terminology

**Module:** Pattern Knowledge  
**Version:** V1.0.0  
**Status:** Frozen (Terminology Specification)

---

# 1. Purpose

This document defines canonical terminology for Pattern / Ge Ju knowledge.

Shared fundamental terms are referenced from Fundamental Knowledge and are not redefined here.

---

# 2. Term Contract

Every term shall include:

| Field | Requirement |
|-------|-------------|
| term_id | Stable unique identity |
| canonical_term | Canonical label |
| definition | Precise meaning in pattern domain |
| scope | Pattern Knowledge scope |
| aliases | Alternate labels |
| relationships | Related terms / fundamental references |
| language | Locale |
| version | Module-aligned version |

---

# 3. Core Pattern Families

## Standard Pattern

Definition: Canonical ordinary Ge Ju established by standard structural conditions.

Scope: Pattern Category.

Aliases: Chính Cách, Regular Pattern.

Relationships: distinct from Special, Follow, and Transformation Patterns.

## Special Pattern

Definition: Ge Ju established by special structural conditions outside ordinary standard formation.

Scope: Pattern Category.

Aliases: Đặc Cách, Special Ge Ju.

Relationships: may override or compete with Standard Patterns via Priority Concepts.

## Follow Pattern

Definition: Ge Ju in which chart composition follows a dominant directional force.

Scope: Pattern Category.

Aliases: Từ Cách, Follow Ge Ju.

Relationships: related to Follow direction concepts and Pattern Conditions.

## Transformation Pattern

Definition: Ge Ju involving transformation-based structural establishment.

Scope: Pattern Category.

Aliases: Hóa Cách, Transformed Pattern.

Relationships: related to transformation conditions and compatibility constraints.

---

# 4. Condition and Resolution Concepts

## Pattern Condition

Definition: Declarative requirement that must be satisfied for pattern eligibility or confirmation.

Scope: Pattern Conditions.

Aliases: Eligibility Condition, Formation Condition.

Relationships: linked to PatternIdentity and Decision Concepts.

## Pattern Priority

Definition: Ordering concept used when multiple pattern candidates compete.

Scope: Pattern Priority.

Aliases: Ge Ju Priority, Candidate Priority.

Relationships: related to Pattern Compatibility and Pattern Exceptions.

## Pattern Compatibility

Definition: Relationship describing whether patterns may coexist, exclude, or specialize one another.

Scope: Pattern Compatibility.

Aliases: Mutual Exclusion, Compatible Patterns.

Relationships: related to Pattern Priority and PatternIdentity.

## Pattern Exception

Definition: Exceptional case that specializes or overrides ordinary pattern determination knowledge.

Scope: Pattern Exceptions.

Aliases: Special Case Pattern Rule Concept.

Relationships: related to Priority Concepts and Special Patterns.

## Pattern Confidence

Definition: Declarative confidence class for pattern determination knowledge quality.

Scope: Pattern Confidence.

Aliases: Ge Ju Confidence.

Relationships: related to Confidence Aggregation Formula Concepts.

# 5. Additional Required Term Families

Terminology shall also cover:

- individual standard / special / follow / transformation pattern identities as published
- Decision Concept labels
- Reference Table class names
- Formula Concept names
- Validation Concept names
- Evaluation Dimension names
- rejected-candidate and selected-pattern labels used by Pattern Engine outputs

---

# 6. Non-Redefinition Rule

Stem, Branch, Wu Xing, Ten Gods base identities, and shared relation taxonomies remain owned by Fundamental Knowledge.

Pattern Terminology may specialize pattern-usage labels but must reference fundamental identities.

---

# 7. Acceptance Criteria

Terminology is accepted when all mandatory pattern terms include definition, scope, aliases, and relationships, and remain consistent with Fundamental Knowledge.
