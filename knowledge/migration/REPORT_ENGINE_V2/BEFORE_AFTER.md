# BEFORE / AFTER — Customer reading

Date: 2026-08-13

---

## Document shape

| | Before | After |
|--|--------|-------|
| Title | Báo cáo luận giải Bát Tự | Báo cáo tư vấn (or đồng hành phụ huynh) |
| Opening | Chart tables | Cover: person + consulting class |
| Body | 17 engine/template sections | Identity → Career → Executive |
| Empty domains | “Chưa đủ dữ liệu…” | Omitted |
| Footer | Report V1 · engine_version | BTE · Báo cáo tư vấn |
| Appendix | Mixed into body | Advisor Mode only |

## CASE_0001

| | Before | After |
|--|--------|-------|
| First page | Họ tên + Tứ Trụ + ngũ hành scores | Cover “Người tự gánh” |
| Identity | Not printed | “Tôi là ai?” — tự gánh / tự đẩy tiến độ |
| Career | Placeholder “11. Nghề nghiệp” or missing | Career Feature — working style, environment, risks |
| Executive | Stitched engine summary | Executive Consulting — who / system / priorities / close |
| Engine tables | Printed | Absent |

Reads as **one consulting report**, not three engines.
