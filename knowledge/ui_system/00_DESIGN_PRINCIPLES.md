# 1. Purpose

This document is the highest Visual System V2 specification.

Every later token, card, and state rule must obey these principles.

---

# 2. Design philosophy

BTE is a commercial analytical product.

Not an admin panel.

Not a developer tool.

Not a spreadsheet.

Not a marketing site.

Not a consumer widget collage.

Every screen should resemble a prepared consulting report: ordered, calm, and trustworthy.

---

# 3. Core goals

| Goal | Meaning |
|------|---------|
| Premium | Restraint, materials, and hierarchy. No visual noise. |
| Professional | Consultant tone. Precise. Scholarly. |
| Readable | Typography and whitespace before decoration. |
| Trustworthy | Stable layout. Explain before recommend. |
| Calm | One accent. Subtle elevation. No excitement. |

---

# 4. Experience order

Trust

↓

Understanding

↓

Action

Technology supports the experience. It never becomes the experience.

---

# 5. Mandatory principles

1. Hierarchy first. Primary, secondary, and tertiary must be obvious.
2. Whitespace is information. Do not fill empty space with borders.
3. Typography over decoration.
4. One purpose per card.
5. Color communicates meaning, never decoration.
6. One primary accent per screen.
7. Cards are independent. One card never drives another card’s layout.
8. Layout controls data. Data never explodes the layout.
9. Progressive disclosure: overview → evidence → analysis → action.
10. Consistency over creativity.

---

# 6. Visual weight

| Weight | Surfaces |
|--------|----------|
| Primary | Hero, critical findings, primary CTA |
| Secondary | Analysis cards, charts, metrics |
| Tertiary | Reference, knowledge, metadata |

Decorative elements have minimal weight.

---

# 7. What Visual System V2 is not

- A new Runtime
- A new Narrative
- A Dashboard redesign
- A Card geometry redesign
- A PDF redesign
- A token invention layer

It specifies existing Foundation and Design System values for Commercial UI V2.

---

# 8. Acceptance

Visual System V2 is valid only when a screen feels like a commercial consulting product: premium, professional, readable, trustworthy, and calm.
