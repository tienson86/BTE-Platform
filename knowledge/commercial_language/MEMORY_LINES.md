# MEMORY_LINES — Layer 5 (Memorable Closing)

Version: 1.2.0

---

## Purpose

Leave **one** line the customer can repeat — without slogans or case leakage.

---

## Rules

1. ≤ 20 words when possible.  
2. Must derive from `primary_insight` or the report’s dominant theme.  
3. Must be chart-specific (CASE-0001 memory ≠ CASE-0002 memory).  
4. No stems-only closings (“Nhớ Nhâm”).  
5. No fear closings.  
6. One memory line per report (not per section), unless a section is sold standalone.

---

## Shapes

| Shape | Template stance |
|-------|-----------------|
| Identity | “Bạn [operating truth] — và mạnh hơn khi [support/action].” |
| Career | “Công việc hợp bạn khi [style] được đặt đúng chỗ, không khi [avoid].” |
| Executive | “Điểm then chốt: [insight consequence in life words].” |

---

## Quality check

Ask:

- Would the customer text this to a friend?
- Does it still make sense without BaZi vocabulary?
- Does it match **this** claim plan’s primary theme?

If any answer is no → rewrite.
