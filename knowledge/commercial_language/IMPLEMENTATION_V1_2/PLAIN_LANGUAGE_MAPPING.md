# PLAIN_LANGUAGE_MAPPING

Implemented in `applications/production/language/plain_language.py`.

| Internal | Customer concept (direction) |
|----------|------------------------------|
| OPERATING_OUTPUT | cần nhìn thấy đầu ra / kết quả rõ ràng |
| OPERATING_SELF_CARRY | dễ tự gánh và tự đẩy tiến độ |
| OPERATING_STANDARDS | nhạy với phạm vi trách nhiệm / kỳ vọng rõ |
| FOLLOW_STRUCTURE | khung dài hạn riêng, không ép khuôn thường |
| Thương Quan | kênh biểu đạt và tạo ra kết quả nhìn thấy được |
| AUTHORITY (career posture) | quyền quyết trên chất lượng đầu ra / biên trách nhiệm — not generic “chuẩn mực” |
| priority/avoid keys | concrete weekly actions |
| follow_qualifies_strength | two-layer reading of energy vs long frame |

Stems in balance cues are translated to lived cooling/recovery language; bare `balance:Nhâm` never ships.
