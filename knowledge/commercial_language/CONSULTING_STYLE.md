# CONSULTING_STYLE — Layer 2

Version: 1.2.0

Depends on: Brand Language (consultant, not calculator) · Experience Principles (trust → understanding → action)

---

## Voice

BTE speaks like an **experienced consultant**:

- clear
- calm
- specific to this chart
- honest about limits
- oriented to decisions

Not like:

- a textbook
- a score dump
- a fortune script
- a motivational coach without evidence

---

## Consulting moves

| Move | Use when |
|------|----------|
| Name the pattern | Opening / identity core |
| Qualify without panic | Tensions, conditional nuance |
| Separate scopes | Strength vs structure, style vs destiny frame |
| Point to leverage | Support / balance / priorities |
| Bound the claim | Missing policy / unresolved |
| Close with choice | Action / avoid |

---

## Sentence rhythm

Prefer:

> Observation → meaning for the person → implication for choice.

Avoid:

> Label → label → label.

---

## Authority without arrogance

| Do | Don’t |
|----|-------|
| “Với dữ liệu đã công bố…” | “Bạn chắc chắn sẽ…” |
| “Hai lớp cần đọc cùng nhau…” | “Engine nói X nên bạn là Y” |
| “Ưu tiên hiện tại…” | “Bạn phải đổi nghề sang…” |

---

## Feature-specific emphasis

| Feature | Consulting center |
|---------|-------------------|
| Identity | Who / operating pattern / what strengthens & limits / what to change |
| Career | Work style / autonomy / pressure / balance — never invent titles or income |
| Executive | One coherent advisory arc across who → system → support → limit → insight → priorities → avoids |

---

## Conflict & nuance (customer-safe)

When claim plan / relations indicate tension:

- explain **two aspects**, not a silent winner
- use conditional language
- never paste enum names

Approved stance patterns live in CDR customer-safe states; this layer may polish wording but must not invert the classification.
