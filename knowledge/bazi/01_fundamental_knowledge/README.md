# 1. Purpose

The Fundamental Knowledge module provides the canonical academic foundation for the entire BaZi Knowledge Canon.

It defines the core concepts, principles, terminology, and theoretical framework upon which all higher-level BaZi knowledge is constructed.

This module serves as the entry point for every other BaZi knowledge module and establishes the common language used throughout the BTE Platform.

---

# 2. Scope

This module contains only foundational knowledge.

It focuses on describing **what the concepts are**, not **how they are interpreted**.

Included topics may include:

- Yin and Yang
- Wu Xing (Five Elements)
- Heavenly Stems
- Earthly Branches
- Hidden Stems
- Qi
- Seasonal Qi
- Growth Phases (Chang Sheng)
- Stem and Branch relationships
- Fundamental terminology
- Classical theoretical principles

---

# 3. Out of Scope

The following topics are intentionally excluded:

- Strength evaluation
- Temperature analysis
- Pattern determination
- Useful God analysis
- Ten Gods interpretation
- Combination rules
- ShenSha interpretation
- Luck Pillars
- Marriage analysis
- Career analysis
- Wealth analysis
- Health analysis
- Children analysis
- Rule Engine logic
- Interpretation templates
- Scoring systems

These topics belong to dedicated modules.

---

# 4. Objectives

The objectives of this module are to:

- Establish a canonical academic foundation.
- Standardize BaZi terminology.
- Provide reusable knowledge records.
- Support all downstream modules.
- Maintain consistency across the Knowledge Canon.

# 9. Development Workflow

Every Knowledge Record shall follow the standard workflow:

1. Knowledge Inventory (`KNOWLEDGE_INVENTORY.md`) — Phase 1
2. Per-record academic design — Phase 2
3. Academic Review — Phase 3
4. JSON generation per approved specs — Phase 4
5. Validation — Phase 5
6. Freeze Module V1.0 — Phase 6
7. Transfer to `02_strength_knowledge` — Phase 7

No Knowledge Record may bypass this workflow.

# 11. Relationship with Other Modules

The Fundamental Knowledge module provides the academic basis for all other BaZi modules.

No other BaZi module should redefine concepts already established here.

Cross-module references shall always reuse the canonical Knowledge Records defined in this module.

---

# 12. Versioning Policy

Versioning follows Semantic Versioning.

- Major: Structural or academic changes.
- Minor: New Knowledge Records.
- Patch: Editorial or metadata corrections.
