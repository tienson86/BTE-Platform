---

# 1. Purpose

Define the official procedure for creating, validating, approving, and maintaining rules within the BTE Rule Database.

---

# 2. Scope

Applies to:

- Strength Rules
- Season Rules
- Temperature Rules
- Pattern Rules
- Combination Rules
- Priority Rules
- Special Case Rules
- Follow Pattern Rules

---

# 3. Preconditions

Before creating a rule:

- Knowledge source identified
- Reference verified
- Rule category selected
- Terminology verified
- Existing rules reviewed

---

# 4. Inputs

Required inputs:

- Knowledge Asset
- References
- Rule Category
- Rule Priority
- Rule Conditions
- Expected Result

---

# 5. Roles and Responsibilities

| Role | Responsibility |
|------|----------------|
| Rule Author | Draft rule |
| Knowledge Reviewer | Verify correctness |
| Technical Reviewer | Verify schema |
| Governance Reviewer | Verify compliance |
| Approver | Approve publication |

---

# 6. Procedure Steps

Step 1 — Identify Rule Candidate

Step 2 — Check Existing Rule Registry

Step 3 — Assign Rule ID

Step 4 — Define Conditions

Step 5 — Define Actions

Step 6 — Assign Priority

Step 7 — Link References

Step 8 — Validate Rule Schema

Step 9 — Submit for Review

---

# 7. Outputs

- Rule Record
- Rule Metadata
- Rule Mapping
- Reference Mapping

---

# 8. Validation

Verify:

- Rule ID
- Unique Conditions
- Valid Priority
- References
- Traceability
- Schema Compliance

---

# 9. Exceptions

Emergency rules require post-release review.
