# BTE Case Study Workflow

## Purpose

Define the lifecycle of official Case Studies used for validation, education and regression testing.

---

## Procedure

1. Select Case
2. Verify Source
3. Prepare Metadata
4. Record Input
5. Record Expected Output
6. Rule Mapping
7. Knowledge Mapping
8. Peer Review
9. Approval
10. Register Golden Case (if applicable)

---

## Outputs

- Case Study
- Metadata
- Rule Mapping
- Golden Dataset (optional)

---

## Validation

- Complete input
- Complete reasoning
- Expected output verified
- References attached
- Traceability complete

---

## KPIs

- Case Completeness
- Rule Coverage
- Golden Case Coverage
