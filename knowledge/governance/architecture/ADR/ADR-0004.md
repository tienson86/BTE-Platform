# ADR-0004 — Knowledge / analysis / presentation separation

| Field | Value |
|-------|-------|
| **Status** | Accepted |
| **Date** | 2026-08-09 |
| **Platform** | 1.0.0 |
| **Deciders** | Architecture Board |

---

## Context

Consultant-facing text, layout, and export historically leaked into scoring and decision code. UI Foundation packs also risk mixing visual tokens with engine models.

---

## Decision

Separate three concerns:

1. **Knowledge / Analysis / Decision / Luck** — facts, scores, gods, timeline impact. No presentation formatting.
2. **Interpretation** — select and assemble structured language candidates. No AI rewrite. No report pagination.
3. **Report** — document structure (RE-1), layout identities (RE-2), in-memory render envelopes (RE-3). No new analytical rules.

UI Foundation V1.0 visual language remains a separate freeze from engine Foundation F-1. Engines MUST NOT import UI packs; UI MUST NOT import engine internals.

---

## Consequences

Positive: brand/presentation can evolve without recomputing Useful God; engines stay testable.

Negative: more snapshots between layers.

Rejected alternative: Report Engine recalculating pattern quality while emitting HTML.
