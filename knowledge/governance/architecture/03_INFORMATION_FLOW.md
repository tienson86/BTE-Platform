# Information Flow Architecture

## Purpose

Describe how knowledge flows through the BTE Platform.

---

# High-Level Flow

```
Reference

↓

Terminology

↓

Knowledge

↓

Rule Database

↓

Sentence Library

↓

Interpretation Engine

↓

Report Engine

↓

Final Report
```

---

# Detailed Flow

References create Knowledge.

Knowledge generates Rules.

Rules generate Sentences.

Sentences generate Interpretation.

Interpretation generates Reports.

---

# Validation
