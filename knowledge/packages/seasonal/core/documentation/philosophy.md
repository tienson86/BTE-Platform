# Seasonal philosophy

Tháng lệnh is the primary clock of elemental qi. Seasonal Core records *which season commands* and *how each element sits in that command* (Vượng / Tướng / Hưu / Tù / Tử).

It does not judge Day Master strength. Strength Core consumes seasonal facts; it owns `strength_score`. Temperature, Pattern, Useful God, and Luck Cycle similarly consume seasonal qi without this package selecting gods or patterns.
