# Override Legality

Legal only when:

- `resolved_useful_god` is published (including `withheld`)
- all prerequisite inputs exist
- an exceptional condition is present
- no prohibition rule fires
- override has not already been applied in the same run

Illegal:

- recomputing Seasonal / Strength / Temperature / Pattern / PEV / Foundation / Priority
- mutating upstream published fields
- overriding without a published decision
- double override
