# Decision Hierarchy

Foundation identifies → Priority resolves → Override may replace the published resolved decision.

```
Useful God Foundation
  ↓ useful_god / decision_*
Useful God Priority
  ↓ resolved_useful_god / decision_priority / resolution_*
Useful God Override
  ↓ final_useful_god / override_* / decision_trace / decision_audit
```

Upstream outputs remain immutable.
