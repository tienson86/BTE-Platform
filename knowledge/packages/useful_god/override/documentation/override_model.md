# Override Model

1. Eligibility — a published decision exists.
2. Prerequisites — all 11 published inputs present.
3. Prohibition — clean high-confidence primary decisions cannot be overridden.
4. Exceptional conditions — follow, transformation, dominant element, contradiction, low confidence.
5. Typed override — at most one override type per run; transformation outranks follow.
6. Publication — new outputs only (`final_*`, `override_*`, `decision_trace`, `decision_audit`).
