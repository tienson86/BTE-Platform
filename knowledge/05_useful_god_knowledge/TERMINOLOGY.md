# Useful God Knowledge Terminology

**Module:** Useful God Knowledge  
**Version:** V1.0.0  
**Status:** Frozen (Terminology Specification)

---

# 1. Purpose

This document defines canonical terminology for Useful God knowledge.

Shared fundamental terms are referenced from Fundamental Knowledge and are not redefined here.

---

# 2. Term Contract

Every term shall include:

| Field | Requirement |
|-------|-------------|
| term_id | Stable unique identity |
| canonical_term | Canonical label |
| definition | Precise meaning in Useful God domain |
| scope | Useful God Knowledge scope |
| aliases | Alternate labels |
| relationships | Related terms / fundamental / upstream references |
| language | Locale |
| version | Module-aligned version |

---

# 3. Core Role Terms

## Yong Shen

Definition: The primary Useful God that most critically balances the chart.

Scope: Useful God Role.

Aliases: Dụng Thần, Useful God.

Relationships: supported by Xi Shen; opposed conceptually by Ji Shen; distinct from Chou Shen.

## Xi Shen

Definition: Favorable God that assists or reinforces the Useful God.

Scope: Useful God Role.

Aliases: Hỷ Thần, Favorable God.

Relationships: supports Yong Shen; distinct from Ji Shen and Chou Shen.

## Ji Shen

Definition: Unfavorable God that harms balance or opposes the Useful God direction.

Scope: Useful God Role.

Aliases: Kỵ Thần, Unfavorable God.

Relationships: opposes or burdens Yong Shen / Xi Shen direction; distinct from Chou Shen.

## Chou Shen

Definition: Idle / secondary god class that is neither primary useful nor strongly unfavorable under declared conditions.

Scope: Useful God Role.

Aliases: Cừu Thần, Nhàn Thần, Neutral / Idle God.

Relationships: residual relative to Yong / Xi / Ji assignments.

# 4. Dependency and Selection Terms

## Seasonal Selection

Definition: Selection frame in which season command influences Useful God candidacy.

Scope: Seasonal Selection.

Aliases: Season-Based Selection.

Relationships: references Fundamental Season Definitions; related to Yong Shen selection.

## Strength Dependency

Definition: Dependency concept linking published Day Master strength class to Useful God candidacy.

Scope: Strength Dependency.

Aliases: Body-Strength Dependency.

Relationships: references Strength Knowledge classifications; does not redefine them.

## Temperature Dependency

Definition: Dependency concept linking published climate class to Useful God candidacy.

Scope: Temperature Dependency.

Aliases: Climate Dependency.

Relationships: references Temperature Knowledge classifications; does not redefine them.

## Pattern Dependency

Definition: Dependency concept linking published Pattern identity to Useful God candidacy.

Scope: Pattern Dependency.

Aliases: Ge Ju Dependency.

Relationships: references Pattern Knowledge identities; does not redefine them.

## Candidate Selection

Definition: Principles for choosing among primary, secondary, and alternative Useful God candidates.

Scope: Candidate Selection.

Aliases: Useful God Candidate Resolution Concept.

Relationships: related to Priority Rules and Confidence Concepts.

## Priority Rules

Definition: Ordering concepts used when multiple Useful God outcomes compete.

Scope: Priority Rules.

Aliases: Useful God Priority Concepts.

Relationships: related to Candidate Selection and role assignment conflicts.

## Confidence Concepts

Definition: Declarative confidence classes for Useful God determination knowledge quality.

Scope: Confidence Concepts.

Aliases: Useful God Confidence.

Relationships: related to Formula Concepts.

# 6. Non-Redefinition Rule

Stem, Branch, Wu Xing, and shared relation taxonomies remain owned by Fundamental Knowledge.

Strength, Temperature, and Pattern classification identities remain owned by their respective Knowledge Modules.

Useful God Terminology may specialize Useful God-usage labels but must reference upstream identities.

---

# 7. Acceptance Criteria

Terminology is accepted when all mandatory Useful God terms include definition, scope, aliases, and relationships, and remain consistent with Fundamental and upstream analytical Knowledge Modules.
