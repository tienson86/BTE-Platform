# 1. PURPOSE

This document defines the canonical visual structure of the **Date Selection Report**.

It specifies:

- report sections
- reading order
- page layout
- information hierarchy
- visual grouping
- typography hierarchy

This document does **not** define:

- analytical calculations
- PDF renderer
- DOCX renderer
- templates
- APIs

---

# 2. DESIGN GOALS

The report must satisfy five objectives.

## Goal 1

Easy to understand for ordinary customers.

No technical or internal algorithm terminology.

---

## Goal 2

Professional enough for consultants to deliver directly to customers.

---

## Goal 3

Readable both on screen and when printed.

---

## Goal 4

Visually consistent with the existing BTE Report Engine.

---

## Goal 5

Preserve analytical truth exactly as generated by Date Selection.

---

# 12. COMPATIBLE HOURS

Section title:

```text id="zwjlwm"
Giờ phù hợp Nhóm Trạch của bạn
```

List style:

```text id="jlwm41"
• Giờ Thìn (07:01–09:00) · Càn (Kim)

• Giờ Tỵ (09:01–11:00) · Khôn (Thổ)

• Giờ Thân (15:01–17:00) · Khôn (Thổ)

• Giờ Dậu (17:01–19:00) · Cấn (Thổ)
```

No duplicated confirmation lines.

No "Kết quả giờ".

---

# 13. POSITIVE TIMES

Section title:

```text id="jlwm42"
Các thời điểm đẹp
```

Group by positive class.

Recommended:

```text id="jlwm43"
Đại An

• Giờ Thìn
07:01–07:20

• Giờ Dậu
17:21–17:40

----------------

Tốc Hỷ

• Giờ Thìn
07:41–08:00

----------------

Tiểu Cát

• Giờ Tỵ
10:21–10:40
```

This presentation allows customers to choose according to purpose.

---

# 14. VISUAL SEPARATION

Every recommendation block should contain:

```text id="jlwm44"
Date

↓

Day Information

↓

Compatible Hours

↓

Positive Times
```

Separated by subtle dividers.

Avoid heavy borders.

---

# 15. RECOMMENDATION ORDER

Recommendations appear in canonical ranking order.

Example:

```text id="jlwm45"
01

02

03

04

05
```

Do not reorder inside the report.

---

# 16. PAGE BREAKS

Avoid splitting one recommendation block across two pages whenever practical.

Preferred:

One complete recommendation stays together.

---

# 17. SECTION 04

# HƯỚNG DẪN THAM KHẢO

Purpose:

Help customers understand the three positive classes.

Recommended:

```text id="jlwm46"
Đại An

Phù hợp với xu hướng ổn định,
an cư và phát triển bền vững.

----------------

Tốc Hỷ

Phù hợp với các công việc
mong muốn tiến triển nhanh.

----------------

Tiểu Cát

Phù hợp với các công việc
cầu thuận lợi và phát triển.
```

Language must remain advisory.

Never deterministic.

Use BTE theme.

- monochrome printers
- office laser printers
- grayscale export

# 27. DOCX LAYOUT

Must visually resemble PDF.

# 28. REPORT LENGTH

Typical:

1–4 pages.

Depends on:

Number of recommendations.

Do not artificially pad pages.

---

# 29. EMPTY STATES

If no recommendation exists:

Display:

```text id="jlwm4a"
Không tìm thấy ngày phù hợp
trong khoảng thời gian đã chọn.
```

Do not generate empty recommendation sections.

---

# 30. ACCEPTANCE

Layout PASS when:

✓ Professional appearance

✓ Consistent typography

✓ Person information readable

✓ Recommendation blocks easy to scan

✓ Compatible hours understandable

✓ Positive times grouped clearly

✓ Guidance concise

✓ PDF printable

✓ DOCX readable

✓ Same analytical truth
