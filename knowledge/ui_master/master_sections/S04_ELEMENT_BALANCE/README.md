# 1. Mục tiêu

S04 là Section trực quan hóa sự phân bố Ngũ hành của toàn bộ lá số.

Đây là phần đầu tiên thể hiện năng lực phân tích của hệ thống BTE.

Không chỉ hiển thị dữ liệu, S04 giúp người dùng hiểu nhanh:

- Hành nào vượng.
- Hành nào suy.
- Hành nào thiếu.
- Hành nào dư.
