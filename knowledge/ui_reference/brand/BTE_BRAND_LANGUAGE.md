# 1. Purpose

This document defines the identity of the BTE Platform.

The Design System defines structure.

The Visual Language defines appearance.

The Brand Language defines experience.

It answers a single question.

"What should users feel when using BTE?"

Every future design decision should reinforce this identity.

---

# 2. Product Identity

BTE is not merely software.

BTE is a professional analytical platform for BaZi and traditional metaphysics.

The product should feel like

an experienced consultant,

not

an automated calculator.

Users should experience

clarity,

authority,

trust,

and confidence.

Every interaction should reinforce the perception that BTE is a professional decision-support platform.

# 4. Core Design Values

Every visual decision should reinforce one or more of these values.

Clarity

Users immediately understand what matters.

Precision

Information is presented accurately and consistently.

Authority

The interface inspires confidence through structure and restraint.

Trust

Nothing appears exaggerated or misleading.

Focus

Only essential information receives visual emphasis.

Balance

Visual composition should feel calm and harmonious.

Respect

The interface respects the user's attention and cognitive effort.

# 8. BTE Signature Experience

Every professional product possesses a distinctive experience that users immediately recognize.

This experience is not created by logos or colors alone.

It is created by consistent presentation, predictable structure, and a recognizable analytical style.

BTE should establish its own signature experience.

When users view a BTE report without seeing the logo,

they should still recognize it as a BTE analysis.
