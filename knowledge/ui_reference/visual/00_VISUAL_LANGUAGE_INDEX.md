## Rules for Implementers

1. Do not invent spacing, type scales, colors, or shadows.
2. Prefer whitespace over borders; typography over decoration.
3. Apply Transform Guide rules when upgrading legacy UI.
4. Result Page Visual V2 (`data-visual="v2"`) is the reference implementation.
