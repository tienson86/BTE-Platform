## 1. Purpose

Establish **Real Case Validation**: evaluate BTE consulting quality on a defined Golden Case set to discover gaps before expanding Knowledge.

This sprint answers: *Where does current product (Wave 1.1 integrated) succeed or fail as consultation?*

It does **not** author Knowledge Units or change engines.

## 3. Method

```
Golden Case profile
        ↓
NarrativeResult (+ Wave 1.1 Commercial Bundle when applicable)
        ↓
Human / structured review (EPIC 5 scorecard + this template)
        ↓
Gap classification (Missing/Weak Knowledge · Evidence · Narrative)
        ↓
Prioritized Improvement Backlog
```

Evaluation in Sprint A used **representative analysis bags** aligned to Golden Case intents (not birth-date re-authoring). Product may later bind profiles to anonymized real charts without changing this methodology.
