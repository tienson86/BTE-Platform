# Example Knowledge Packages

These examples demonstrate the KD-3 Knowledge Package Specification.

They are **specification fixtures only**.

- They are not production knowledge.
- They do not add analytical BaZi rules.
- They must not be loaded by engines as live rule content.

| Folder | package_id | type | status |
|--------|------------|------|--------|
| `minimal_package/` | `ex_00_minimal` | minimal | draft |
| `analytical_package/` | `ex_01_analytical_demo` | analytical | validated |
| `interpretation_package/` | `ex_02_interpretation_demo` | interpretation | validated |
| `report_package/` | `ex_03_report_demo` | report | validated |

Catalog: `EXAMPLE_INDEX.json`.
