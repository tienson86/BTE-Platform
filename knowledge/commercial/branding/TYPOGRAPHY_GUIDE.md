# Typography Guide

Version: 1.0.0  
Sprint: Beta-4

Commercial and marketing type must follow Foundation Visual Language. **Do not invent a second scale.**

SSOT: `knowledge/ui_reference/visual/VISUAL_LANGUAGE_SYSTEM.md` §9.

## Levels (reference)

| Level | Use | Size | Weight |
|-------|-----|------|--------|
| Display | Hero numbers only | 40px | Bold |
| H1 | Page title | 32px | Bold |
| H2 | Section | 24px | SemiBold |
| H3 | Card / subsection | 20px | SemiBold |
| H4 | Group | 18px | Medium |
| Body | Reading | 16px | Regular |
| Caption | Support | 14px | Regular |
| Meta | Auxiliary | 12px | Medium |

## Rhythm

Line length 45–75 characters. Body line-height ~150%. Weight before color. Spacing before borders.

## Marketing vs product

Product UI already implements this scale. Landing pages may use the same steps; they may not introduce display fonts that fight the consultant tone (no novelty script as body type).

## Pairing

One primary text family for UI and one compatible family for long-form marketing is enough. Name the licensed families in the brand asset sheet **[TBD]** after license check.
