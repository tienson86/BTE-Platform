# Icon Guide

Version: 1.0.0  
Sprint: Beta-4

SSOT: Visual Language §13.

## Style

Simple, consistent stroke, professional. Icons support hierarchy; they do not decorate.

## Usage

- One metaphor per action  
- Align to text baseline  
- Inherit semantic color (success / warning / danger / information / neutral)  
- Do not use illustrative occult clip-art as UI icons  

## Density

Prefer fewer icons. If a label is clear, skip the icon.

## Marketing

Launch graphics may use a small set of the same icon family. Do not mix three icon libraries on one page.
