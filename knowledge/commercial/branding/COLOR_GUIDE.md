# Color Guide

Version: 1.0.0  
Sprint: Beta-4

**Do not invent commercial colors.** Roles come from Visual Language §10.

## Roles

| Role | Meaning |
|------|---------|
| Primary | Brand identity (one accent per surface) |
| Secondary | Navigation / quiet structure |
| Success | Positive findings (green family) |
| Warning | Attention (amber) |
| Danger | Critical issues (red) |
| Information | Clarifying notes (blue) |
| Neutral | Supporting content (gray) |

## Rules

- One primary accent per screen or hero  
- Backgrounds stay subtle  
- Color is the last emphasis layer (after type, space, contrast)  
- No extra “lucky gold / mystic purple” palettes for launch campaigns  

Token values remain in the Design System packs. Marketing must sample from product tokens or approved brand board, not from a freelance moodboard.
