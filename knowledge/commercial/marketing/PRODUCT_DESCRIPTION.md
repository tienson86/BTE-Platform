# Product Description

Version: 1.0.0  
Sprint: Beta-4

## Short (50 words)

BTE is a professional BaZi analytical platform. It helps consultants and serious learners run structured analysis and read clear reports — with explanation before recommendation. It is decision support, not entertainment fortune-telling.

## Medium (120 words)

BTE Product v1.0 is a commercial analytical platform for traditional BaZi. Users enter birth data, run a stable analysis pipeline, and receive a consultant-style report designed for trust and understanding. Optional learning content explains terms used in the report. Organizations can discuss private deployment and API v1 integration. The product does not claim to predict fate or replace human judgment.

## Store / directory blurb

Professional BaZi analysis and reports. Explainable. Calm. Built for practitioners.
