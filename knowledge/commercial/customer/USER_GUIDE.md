# User Guide

Version: 1.0.0  
Sprint: Beta-4  
Audience: non-technical users

## What BTE is

BTE helps you study a BaZi chart in a clear, professional way. It is a consultant-style analysis product, not a fortune game.

## Main areas you will use

| Area | What you do there |
|------|-------------------|
| New analysis | Enter birth data and run analysis |
| Report | Read structured results |
| History / cases | Reopen past work if your plan includes it |
| Knowledge center | Learn concepts used in the report (if enabled) |

Exact menu names follow the live Product UI. This guide does not rename screens.

## Typical session

1. Confirm you have the right person and birth data.  
2. Run one analysis.  
3. Read overview → structure → interpretation → suggestions.  
4. Take notes for your client conversation.  
5. Export or share only if your license and privacy rules allow.

## Good habits

- Double-check timezone and calendar type.  
- One person per analysis.  
- Do not promise clients a guaranteed future.  
- More in `BEST_PRACTICES.md`.
