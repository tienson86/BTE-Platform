# Quick Start

Version: 1.0.0  
Sprint: Beta-4  
Audience: non-technical users

Welcome to BTE. In about fifteen minutes you can run your first analysis and open a report.

## Before you begin

You need:

- Access to the BTE product (link and sign-in method your administrator gave you)  
- Birth date, birth time if known, place/timezone, and calendar type (solar/lunar as your practice uses)

If the birth time is unknown, note that in the form comments if available, and read the report more cautiously.

## Four steps

1. Open BTE and sign in (or open the link you were sent).  
2. Start a new analysis. Enter birth details carefully.  
3. Wait until the analysis finishes. Do not refresh repeatedly.  
4. Open the report. Start with the overview, then the main sections. Use `REPORT_READING_GUIDE.md`.

## What success looks like

You can explain, in your own words, what the report is saying — not recite a “lucky number.”

## If something fails

See `TROUBLESHOOTING.md`. Keep any reference number shown on screen (Request ID) for support.
