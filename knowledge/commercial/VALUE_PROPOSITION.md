# Value Proposition

Version: 1.0.0  
Sprint: Beta-4

## For

Consultants, studios, educators, and organizations that need professional BaZi analysis they can explain.

## Who need

Consistent charts, interpretable reports, and a calm product experience that does not embarrass them in front of a client.

## BTE provides

A frozen, versioned analytical platform: calendar → chart → analysis → interpretation → report, presented as a consultant would: clear hierarchy, evidence, and next-step language.

## Unlike

Apps that output a number or a mystical paragraph with no structure.

## So that

Practitioners spend time on judgment and conversation, not on rebuilding the chart pipeline or defending unexplained results.

## Proof points (product, not legal claims)

- Architecture Freeze (AF-1) for a stable commercial surface
- Public API v1 for integration
- Operational runbooks and health model for production hosting
- Customer guides for first analysis and report reading
