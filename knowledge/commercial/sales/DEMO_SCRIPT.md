# Demo Script

Version: 1.0.0  
Sprint: Beta-4  
Length: 20–25 minutes

## 0:00 — Frame

“BTE is a professional analysis product. We will not show a mystical animation. We will show a session you could run with a client.”

## 0:03 — Context

Agree a sample question (e.g. career discussion). Use **demo data the customer agrees is fictional or authorized**.

## 0:06 — Enter analysis

Show careful birth-data entry. Mention timezone. Submit once.

## 0:10 — Report walkthrough

Overview → structure → one interpretation section → one next step. Stop. Let them talk.

## 0:18 — Knowledge Center (if enabled)

Open one term, return to the report.

## 0:22 — Close

“This is v1.0 frozen platform. Next step is a consultation on rollout, not a custom engine.” Point to onboarding pack.

## Never in demo

Live production customer PII. Promising unreleased features. Editing Knowledge packages on screen.
