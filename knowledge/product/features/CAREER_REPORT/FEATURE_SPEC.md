# Feature Spec — Career Decision Report

| Field | Value |
|-------|-------|
| Document | FEATURE_SPEC |
| Version | 1.0.0 |

---

## 1. Objective

Help the customer decide **career direction** in practical terms: work style, environment, leadership vs specialist, employment vs business posture, risks, current focus, and actions.

## 2. Inputs (interpretation only)

| Input | Career role |
|-------|-------------|
| Strength Interpretation | Load capacity, endurance under work pressure |
| Ten Gods Interpretation | Contribution style, responsibility rhythm |
| Destiny Structure Interpretation | Long-path / standards-oriented frame |
| Balance Strategy Interpretation | What to do / avoid to stay sustainable at work |

**Forbidden:** raw scores, rule IDs, pillar dumps, engine traces.

## 3. Luck / timing transparency

If Luck interpretation is unavailable:

- Do **not** invent year/month timing for job moves
- State limitation in Current Career Focus (and Summary if needed)
- Give focus based on structure + operating style + balance only

## 4. Non-goals

- Not industry prediction lists
- Not salary forecasting
- Not a full Identity Report (Feature 01)
- Not a life timeline

## 5. Success — Commercial Test

After reading only this report, customer can answer:

1. What kind of work suits me?  
2. What environment helps me perform best?  
3. What is my biggest career risk?  
4. What should I focus on now?  
5. What should I avoid?
