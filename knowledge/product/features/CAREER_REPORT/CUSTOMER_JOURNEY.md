# Customer Journey — Career Decision Report

| Field | Value |
|-------|-------|
| Document | CUSTOMER_JOURNEY |
| Version | 1.0.0 |

---

## Journey map

```
Receive Core / Identity context (optional)
      ↓
Open Career Decision Report
      ↓
See career profile + working style
      ↓
Clarify environment + leadership/specialist + employment/business
      ↓
Face main risks honestly
      ↓
Get current focus + 3 actions
      ↓
Decide next work move with clearer criteria
```

## Emotional arc

| Stage | Feeling | Report job |
|-------|---------|------------|
| Open | “Just tell me what job to do” | Reframe: direction & fit, not magic job title |
| Middle | “This matches how I work” | Style / environment / role posture |
| Tension | “What’s the real risk?” | Career risks without fear-mongering |
| Close | “I know what to do at work this month” | Focus + actions + summary |

## Trust moments

- Explicitly refuse fake timing when Luck is unavailable  
- Refuse fake industry lists  
- Separate “how you contribute” from “what brand you must join”
