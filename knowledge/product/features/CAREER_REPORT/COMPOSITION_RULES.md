## 1. Synthesis only

No paste of Strength / Ten Gods / Pattern / Useful God chapters.

Claim → theme → one career consultant voice.

## 2. Career “so what?” gate

Keep a paragraph only if it changes a **career decision**:

- role type
- environment choice
- leadership vs depth
- employment vs business posture
- risk to avoid
- focus / next action

## 3. Do not invent

| Forbidden inventions |
|----------------------|
| Exact job titles as destiny |
| Industry lists without evidence |
| Promotion dates / lucky years without Luck interpretation |
| Income guarantees |
| “You must quit” absolute commands |

## 4. Terminology

Prefer: responsibility, standards, delivery, depth, ownership, output, burnout risk.  
Avoid unless necessary: traditional god/pattern labels — if used, translate immediately into work meaning.

## 5. Theme ownership (career)

| Theme | Prefer section |
|-------|----------------|
| Endurance under load | 1 or 6 |
| Responsibility operating style | 2 |
| Standards / long frame | 1 or 3 |
| Leadership / ownership posture | 4 |
| Output vs over-carrying | 6–8 |

## 6. Timing rule

If Luck interpretation Unavailable:

> We can advise **direction and operating fit**. We cannot honestly time a move by year/month until life-timeline interpretation is available.

State once clearly; do not invent compensating forecasts.
