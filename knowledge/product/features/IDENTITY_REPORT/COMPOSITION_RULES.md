# Composition Rules — Identity Report

| Field | Value |
|-------|-------|
| Document | COMPOSITION_RULES |
| Version | 1.0.0 |

---

## 1. Synthesis, not concatenation

Do **not** paste Strength then Ten Gods then Pattern.

Extract claims → resolve themes → write one consultant voice.

## 2. “So what?” gate

Before keeping a paragraph, ask:

- Does this change how the customer sees themselves?
- Does this change a decision or habit?
- If removed, is the report weaker?

If all three are “no,” delete.

## 3. Evidence basis

Every claim must trace to interpreted domain conclusions (not invented lifestyle advice).

| Allowed | Forbidden |
|---------|-----------|
| Endurance from Strength interpretation | Inventing illness diagnoses |
| Responsibility rhythm from Ten Gods interpretation | Dumping all ten gods |
| Long-frame from Structure interpretation | Teaching pattern theory |
| Output / unload from Balance interpretation | Copying CASE master verbatim as a chapter stack |

## 4. Duplicate control (identity themes)

One customer mention per theme inside the report:

| Theme | Prefer section |
|-------|----------------|
| Endurance / capacity | 1 or 3 |
| Responsibility operating style | 2 or 5 |
| Long-frame / standards | 1 or 6 |
| Over-carrying / no release | 4 or 7 |
| Create output to rebalance | 7 or 8 |

## 5. Conflict handling

If domains appear to disagree, write **qualified** language (different scopes), never pick silently.

Example: strong endurance + need to release pressure = not a contradiction; it is the identity tension.

## 6. Commercial tone

- Consultant, not calculator  
- Natural Vietnamese (sample) / professional prose  
- No flattery, no fear-mongering  
- Actionable without sounding like a generic self-help list  

## 7. Identity Summary rules

Section 9 must stand alone as a shareable blurb:

- 5–7 sentences  
- No section headers inside  
- No jargon  
- Answers Who / Strong / Hold-back / Environment / Start in compressed form
