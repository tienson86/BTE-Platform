## Purpose

Define the **official commercial packages** for BTE V1.

Packages are based on **customer needs**, not technical modules (engines, packs, or domains).

This is **not**:

- a Feature implementation task
- an Engine task
- a Knowledge / Rule / Reasoning task
- a Production Pipeline change

## Design principles

1. Sell answers to life questions — not domain modules.  
2. Honesty over completeness — Unavailable stays Unavailable.  
3. Clear upgrade path — each package is complete for its job, not a crippled demo.  
4. Consultant brand — packaging must feel like consulting products, not calculator SKUs.
