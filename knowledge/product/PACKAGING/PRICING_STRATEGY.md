# Pricing Strategy

| Field | Value |
|-------|-------|
| Document | PRICING_STRATEGY |
| Version | 1.0.0 |
| Rule | **No exact prices** — bands only |

---

## Price bands

| Band | Meaning | Typical buyer mindset |
|------|---------|------------------------|
| **Low** | Impulse / first trust | “I’ll try this once.” |
| **Medium** | Decision support | “This should help me choose.” |
| **High** | Serious consulting substitute | “This should feel like a real session.” |
| **Premium** | Professional tool + deliverable | “This supports my practice / clients.” |

---

## Package × band

| Package | Band | Relative stance |
|---------|------|-----------------|
| A Quick Insight | **Low** | Entry; complete for identity only |
| B Professional Consulting | **Medium** | Clear step up; work-decision value |
| C Master Consulting | **High** | Flagship consumer consulting |
| D Advisor Edition | **Premium** | Highest; includes responsibility tooling |

---

## Relative value ladder (not currency)

```
A (Low)
  <  B (Medium)
       <  C (High)
            <  D (Premium)
```

Each step must feel worth the jump via **new customer outcomes**, not unlocked jargon.

---

## Discount / promo posture (policy only)

- Prefer time-limited upgrades A→B / B→C over permanent cheapening of C/D.  
- Never discount D into consumer casual territory — protects advisor positioning.  
- Honesty features (limits disclosure) are never paywalled.

---

## What price must never signal

| Bad signal | Why |
|------------|-----|
| “More engines = higher price” | Breaks consultant brand |
| “Pay to see luck dates” without interpretation readiness | Overclaim risk |
| D priced like A | Destroys advisor segment |
