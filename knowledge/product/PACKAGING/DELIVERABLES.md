## Deliverable catalog

| Code | Deliverable | Description |
|------|-------------|-------------|
| WEB | Web Result | On-screen customer reading experience |
| PDF-ID | Identity PDF | Feature 01 formatted report |
| PDF-CR | Career PDF | Feature 02 formatted report |
| PDF-FULL | Full Consulting PDF | Identity + Career + Executive/Master synthesis |
| SUM-ID | Identity Summary | 5–7 sentence share card |
| SUM-CR | Career Summary | 5–7 sentence career decision card |
| SUM-EX | Executive Summary | Shareable consulting conclusion |
| EXEC | Executive Consulting | Full priorities / avoids / conclusion document |
| MASTER | Master Consulting Narrative | Integrated consultant prose experience |
| ADV-VIEW | Advisor View | Availability, limits, claim structure (not client-facing dump) |
| ADV-NOTES | Advisor Notes Export | Space for practitioner notes + client handoff pack |

## Package → deliverables

| Package | Deliverables |
|---------|--------------|
| **A** | WEB + PDF-ID + SUM-ID |
| **B** | WEB + PDF-ID + PDF-CR + SUM-ID + SUM-CR |
| **C** | WEB + PDF-FULL + SUM-EX (+ embedded Identity/Career) + EXEC + MASTER |
| **D** | All of C + ADV-VIEW + ADV-NOTES |

---

## Format principles

- PDF is the keepable artifact; Web is the reading experience.  
- Summaries are shareable without exposing internals.  
- Advisor deliverables never become the client’s default view.
