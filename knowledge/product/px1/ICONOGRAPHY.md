# Iconography — Result Experience V2

Version: 2.0.0  
Status: **OFFICIAL — Design Only**  
Date: 2026-08-09  
Sprint: Phase X · PX-1  
Source: Visual Language §13 · PACK_03 · PACK_05

---

## 1. Purpose

Icons reinforce meaning.  
They never replace Vietnamese text.

---

## 2. Style rules

- One icon family for the whole platform  
- Consistent stroke, corner, and optical size  
- Icons inherit semantic color (Primary / Warning / Danger / Neutral)  
- No playful, mystical, or emoji-as-icon systems on Result  

---

## 3. Placement

Icons may precede labels.

Allowed anchors:

| Place | Intent |
|-------|--------|
| Consultation status | Reinforce Ready / Limited / Error |
| Warning cards | Caution affordance |
| Expand / collapse | Disclosure chevron |
| Domain tag (optional) | Quiet life-domain cue |
| Primary / secondary buttons | Only if DS button pattern includes an icon |

Not allowed:

- Icon beside every summary bullet  
- Icon-only Hero  
- Icon-only section titles  
- Decorative mandala / mystic glyphs as chrome  

---

## 4. Domain icons (optional)

If used, they are secondary to the Vietnamese title.

| Domain | Title (required) | Icon role |
|--------|------------------|-----------|
| Sự nghiệp | Required text | Optional quiet cue |
| Tài chính | Required text | Optional quiet cue |
| Quan hệ | Required text | Optional quiet cue |
| Sức khỏe | Required text | Optional quiet cue |
| Vận trình | Required text | Optional quiet cue |

Never use English tooltip-only icons for domains.

---

## 5. Accessibility

- Functional icons have an accessible name in Vietnamese  
- Decorative icons are hidden from screen readers  
- Expand chevrons are not the only indicator — visible text **Xem thêm** / **Thu gọn** remains  
- Color of icon is never the only meaning  

---

## 6. Density

Reserve icons for important visual anchors.

If a section already has a clear Section title, it does not need a large leading icon.

---

## 7. Forbidden

- Mixed icon libraries on one page  
- Animated spinning ornaments  
- Using icons to hide English labels  
- Status communicated only by a colored dot  

---

## 8. Stop line

Iconography supports consultant calm. Text remains the source of meaning.
