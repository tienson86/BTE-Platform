# UX Principles — Result Experience V2

Version: 2.0.0  
Status: **OFFICIAL — Design Only**  
Sprint: Phase X · PX-1

Companion to `DESIGN_PRINCIPLES.md`. This file states UX behaviors.

---

## 1. Reading first

BTE is a reading-first product.

Scrolling is the main interaction.  
Clicks reveal depth.  
Clicks never gate the core consultation.

---

## 2. One question at a time

Each section and card answers one question.

The interface always implies the next understanding — not the next gadget.

---

## 3. Progressive disclosure

Preview → Expand → Detail.

Open by default: identity, summary, core direction, warnings, domain frames.  
Closed by default: technical apparatus, knowledge, heavy tables, long essays.

---

## 4. Advice before apparatus

Recommendations precede charts.  
Charts precede (optional) technical inspection.

This is the central UX correction of V2 versus calculator-led layouts.

---

## 5. Explain inside the action unit

Users should not hunt a chart to learn why a recommendation exists.

Every rec carries Vì sao and Kết quả kỳ vọng beside Việc cần làm.

---

## 6. Calm pacing

No artificial urgency.  
No competing primaries.  
No decorative motion.

Confidence comes from clarity.

---

## 7. Consistency

Same titles.  
Same card anatomy.  
Same expand labels.  
Same order on every breakpoint.

Familiarity lowers cognitive load.

---

## 8. Failure is still consulting

Empty and error states stay in Vietnamese consultant voice and preserve whatever advice remains valid.

---

## 9. Accessibility is UX

If it cannot be read by keyboard or announced clearly, it is not a complete experience.

---

## 10. Stop line

UX principles operationalize the Manifesto on the Result Page.

END
