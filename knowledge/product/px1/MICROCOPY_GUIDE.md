# Microcopy Guide — Result Experience V2

Version: 2.0.0  
Status: **OFFICIAL — Design Only**  
Date: 2026-08-09  
Sprint: Phase X · PX-1

---

## 1. Purpose

Microcopy is every short string that steers interaction.

All microcopy is Vietnamese.  
Tone stays consultant-grade.

---

## 2. Buttons

| Tier | Pattern | Examples |
|------|---------|----------|
| Primary | Verb + object | **Bắt đầu theo định hướng này** |
| Secondary | Verb + narrower object | **Xem sâu sự nghiệp** |
| Tertiary | Disclosure / navigation | **Xem thêm** · **Đọc thêm** · **Thu gọn** |

Rules:

- Sentence case Vietnamese  
- No `OK`, `Submit`, `Cancel`  
- No `Click here`  
- One Primary label per view  

---

## 3. Expand / collapse

| Intent | Open | Close |
|--------|------|-------|
| Rec detail | **Xem thêm** | **Thu gọn** |
| Analysis | **Xem phân tích chi tiết** | **Thu gọn phân tích** |
| Chart table | **Xem bảng số liệu** | **Ẩn bảng số liệu** |
| Technical section | **Xem chi tiết kỹ thuật** | **Ẩn chi tiết kỹ thuật** |
| Knowledge section | **Đọc thêm** | **Ẩn kiến thức bổ sung** |
| Knowledge card | **Đọc tiếp** | **Thu gọn** |

## 6. Empty (short)

See Empty State Guide for full cards.

Short line examples:

- **Phần này chưa có luận giải trong buổi tư vấn hiện tại.**  
- **Bạn có thể đọc các lĩnh vực khác hoặc xem định hướng chính.**  

---

## 7. Error (short)

- **Không thể hiển thị phần này.**  
- **Hãy thử lại. Nếu vẫn lỗi, quay lại tóm tắt tư vấn.**  

Never: `undefined`, `NaN`, `Exception`, stack fragments.

---

## 8. Chart and technical

- Chart untitled → forbidden. Always a Vietnamese title.  
- Technical field examples: **Lịch** · **Tứ trụ** · **Múi giờ** · **Phiên bản phân tích** · **Mã hồ sơ**  

IDs appear only after the user opens Chi tiết kỹ thuật, with Vietnamese labels.

---

## 9. Forbidden microcopy

| Forbidden | Why |
|-----------|-----|
| Read more / Show more / Details | English |
| Learn more | Marketing English |
| Oops! | Playful |
| Fatal error | Panic |
| N/A | Developer residue |
| TBD | Unfinished product voice |
