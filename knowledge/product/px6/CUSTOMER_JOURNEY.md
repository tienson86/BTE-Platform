# Customer Journey — Canonical

Version: 1.0.0  
Sprint: PX-6

---

## 1. Purpose

One journey. Every screen is a step, not an island.

---

## 2. Canonical path

```
Visitor
  ↓
Landing (Trang chủ)
  ↓
Introduction / Onboarding
  ↓
Create Analysis
  ↓
Analysis Progress
  ↓
Result (consultation)
  ↓
Knowledge (optional, returnable)
  ↓
Save Report
  ↓
Share Report
  ↓
Download PDF / Print
  ↓
History
  ↓
Return Visit (Tổng quan)
  ↓
Premium Consultation (placeholder)
```

---

## 3. Emotional arc

| Stage | User should feel |
|-------|------------------|
| Landing | Calm recognition |
| Onboarding | Prepared, not sold |
| Analysis | Guided, not tested |
| Result | Understood + able to act |
| Knowledge | Curious, not derailed |
| Save / Share / PDF | In control of the artifact |
| Return | Welcomed back |
| Premium | Invited, never pressured |

---

## 4. Rules

1. No dead ends — every state has a next step.  
2. One primary CTA per step.  
3. Knowledge always offers **Quay lại tư vấn**.  
4. Commercial actions sit *after* understanding, not before Hero.  
5. Vietnamese only.  
6. No payment in this sprint.
