# User Flow

Version: 1.0.0  
Sprint: PX-6

---

## First visit

```
Home
  → Onboarding (Welcome → What BTE does → Prepare → Privacy → Expectation)
  → Phân tích mới
  → Ngày sinh → Lá số → Tiến trình
  → Kết quả
  → (optional) Kiến thức → Quay lại kết quả
  → Lưu / Chia sẻ / PDF
  → Hoàn tất
  → Lịch sử hoặc Tổng quan
```

## Return visit

```
Tổng quan
  → Tiếp tục nơi đang dở  OR  Báo cáo gần đây
  → Kết quả
  → Kiến thức gợi ý
  → Đặt tư vấn chuyên sâu (placeholder)
```

## Recovery

```
Lỗi / Trống / 404
  → Thử lại  OR  Về tổng quan  OR  Phân tích mới  OR  Trợ giúp
```

## Knowledge side-path

```
Định hướng / Recommendation
  → Bài liên quan
  → Đọc
  → Quay lại tư vấn   (never replace Result as home)
```
