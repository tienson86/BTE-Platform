# Sharing Model

Version: 1.0.0  
Sprint: PX-6

---

## What can be shared (UX)

A consultation summary card: name, one-line headline, status.  
Not: technical IDs, schema, raw artifact HTML.

---

## Flow

1. User chọn **Chia sẻ**.  
2. Sheet: sao chép liên kết (placeholder) · gửi sau.  
3. Toast: **Liên kết tư vấn đã sẵn sàng để sao chép.**  
4. No network share API in this sprint.

Privacy line: **Chỉ chia sẻ khi bạn chủ động.**
