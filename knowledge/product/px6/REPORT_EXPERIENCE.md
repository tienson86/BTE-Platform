# Report Experience

Version: 1.0.0  
Sprint: PX-6  
Constraint: **No renderer changes. UX modes only.**

---

## Modes

| Mode | Intent | UX |
|------|--------|----|
| **Reading** | Default consultation | PX-1 order, commercial rail below understanding |
| **Print** | Paper / PDF via browser | Hide nav chrome; keep reading order |
| **Presentation** | Calm full-width read | Hide secondary nav noise; keep CTA save |
| **Sharing** | Explain what is shared | Preview card + copy link placeholder |

Modes are presentation classes / dialogs.  
They do not change Report Engine, PDF pipeline, or contracts.

---

## Reading vs commercial rail

```
Hero → Summary → Recommendations → …
  ↓
Commercial actions (Save / PDF / Print / Share / Knowledge / Book)
```

Actions never replace the Primary consultation CTA **Bắt đầu theo định hướng này**.
