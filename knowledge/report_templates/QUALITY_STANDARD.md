# Report Template Quality Standard

**Document:** QUALITY_STANDARD  
**Module:** knowledge/report_templates  
**Version:** V1.0.0  
**Status:** Official  

---

## Purpose

Define quality requirements for Report Template framework records.

---

## Quality Principles

1. **Structure clarity** — sections are ordered and purposeful
2. **One job per section** — avoid overloaded section intent
3. **Sentence grounding** — wording prefers `SEN-*` links
4. **Audience fit** — Audience / Language / Category are coherent
5. **Traceability** — upstream links are explicit
6. **Stability** — Official templates change only via versioned review

---

## Mandatory Completeness (Official)

- [ ] All mandatory metadata fields populated
- [ ] Structure complete (no `_TBD_` placeholders)
- [ ] Domain INDEX updated
- [ ] Registry entry updated when registry is in use
- [ ] At least L2 traceability
- [ ] Quality checklist below passed

---

## Structure Quality Rules

| Rule | Requirement |
|------|-------------|
| Ordered sections | Numbered or clearly sequenced |
| Named sections | No anonymous empty blocks at Official |
| No narrative dump | Framework records outline structure, not full essays |
| Placeholder ban | `_TBD_` not allowed at Official |

---

## Defect Classes

| Class | Example |
|-------|---------|
| Critical | Duplicate Official IDs; empty Official Structure |
| Major | Broken Sentence/Knowledge IDs; audience/language mismatch |
| Minor | Missing optional Reference links |
| Editorial | Typos; unclear section titles |

Critical defects block Official approval.

---

## Non-Goals

This standard does not author report narrative contents in the framework phase.
