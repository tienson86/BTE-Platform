# Citation Rules

**Module:** `knowledge/citation_rules`  
**Version:** V1.0.0  
**Status:** Official Foundation  
**Role:** Platform citation policy for Knowledge Records (no academic interpretation)

---

## Purpose

Define how Knowledge Records and related assets cite bibliographic sources via Reference IDs.

This module does **not** interpret classical content. It only defines citation mechanics.
