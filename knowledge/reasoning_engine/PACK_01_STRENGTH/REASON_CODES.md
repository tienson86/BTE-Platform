# Reason Codes

| Field | Value |
|-------|-------|
| Document | REASON_CODES |
| Version | 1.0.0 |

---

# 1. Rule

Every selected or rejected unit gets a **closed** reason code.

No arbitrary strings.

---

# 2. Selected

```text
SELECTED_CORE_CONCLUSION
SELECTED_HIGH_SALIENCE
SELECTED_REQUIRED_SECTION
SELECTED_CAUSE_PRESENT
SELECTED_CHAIN_ACTION
SELECTED_EDGE_QUALIFIER
SELECTED_WARNING
SELECTED_BUDGET_KEEP
```

---

---

# 4. Insufficient / mode

```text

INSUFFICIENT_DATA_SECTION
DEFERRED_TO_VALIDATION
QUALIFIED_FOR_CUSTOMER
EXPOSED_CONFLICT_VALIDATION
```

---

# 5. Multiple codes

A unit may have one primary code plus secondary codes in diagnostics.

Customer Mode shows none of them.
