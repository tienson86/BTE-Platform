# Reason Codes — FROZEN V1.0

| Field | Value |
|-------|-------|
| Document | REASON_CODES |
| Status | FROZEN |

---

# 1. Rule

Every keep, reject, merge, conflict action, and omission has **exactly one primary** code from this list.

No arbitrary strings.

No synonyms.

---
