# THEME_SELECTION

Primary theme selected from the actual chart — deterministic factors:

1. Multi-domain support / reinforcement boost
2. Specificity (follow structure, operating families)
3. Customer relevance
4. Evidence completeness (claim presence)
5. Conflict / suppression state
6. Novelty vs unsupported CASE-0001-shaped themes
7. Actionable value

**Not used:** literary quality, LLM.

## Anti-overfit

- OVERLOAD_RISK / CAPACITY_STRONG suppressed unless strength is strong/very_strong.
- OPERATING_SELF_CARRY suppressed unless companion family claim exists.
- CASE-0002 must not inherit “gánh thêm / sức bền chịu tải” without supporting claims.
