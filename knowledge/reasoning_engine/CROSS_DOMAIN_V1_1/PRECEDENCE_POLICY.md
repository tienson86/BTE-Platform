# PRECEDENCE_POLICY

Precedence is applied **only** where an existing canonical BTE policy supports it.

## Published refs used

| Relation | Policy |
|----------|--------|
| Follow / special pattern vs ordinary Strength | `STRENGTH_BOUNDARY_MODEL.md` — publish both; lower confidence |
| Follow philosophy | `packages/follow_pattern/.../philosophy.md` |

## Rules

- Special / follow pattern → may **qualify** ordinary strength interpretation (DEPENDENCY_OVERRIDE + CONDITIONAL_NUANCE).
- Useful God depends on chart structure / balance context — conditional with strength.
- Ten Gods dominance does **not** override Pattern (DIFFERENT_SCOPE).
- If no canonical policy exists → UNRESOLVED + blocker (or POLICY_NOT_PUBLISHED when applicable).

**Do not invent metaphysical precedence in code.**
