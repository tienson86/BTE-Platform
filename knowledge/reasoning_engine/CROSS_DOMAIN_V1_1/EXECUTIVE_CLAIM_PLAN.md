# EXECUTIVE_CLAIM_PLAN

Non-prose slots for composers.

| Slot | Content |
|------|---------|
| identity_core | Theme labels + body/structure keys |
| operating_style | Primary Ten Gods / style |
| main_support | Balance or capacity key |
| main_constraint | Theme id or relation id |
| balance_direction | Useful God |
| primary_insight | Selected theme label combo |
| priorities[] | Action keys (not sentences) |
| avoidances[] | Avoidance keys |
| unresolved[] | Blockers / qualified relations |

Composer owns wording. Reasoner owns classification.
