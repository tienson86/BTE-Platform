---

## Principles (to be filled)

1. **Clarity first** — Analysis results must be readable before they are decorative.
2. **One composition** — Primary views read as a composed product surface, not a generic dashboard collage.
3. **Canonical consistency** — Portal, Analysis Console, Admin Console, and Mobile share the same tokens and component contracts.
4. **Evidence over invention** — UI copy and structure follow engine outputs; the Design System does not invent domain rules.
5. **Versioned truth** — Approved looks are frozen as canonical; never overwrite prior freezes.
