# Desktop Review Checklist

**Device:** Desktop  
**Version:** 1.0.0  
**Status:** Active template

---

## When to Use

Run this checklist before promoting a desktop canonical markdown/export to **CANONICAL**.

---

## Identity

- [ ] Surface named correctly (Portal / Analysis / Admin)
- [ ] Version filename matches freeze (`…_DESKTOP_V<n>`)
- [ ] Previous desktop versions were **not** overwritten

---

## Layout

- [ ] Matches `04_layouts/desktop_grid.md` (or documented exception)
- [ ] Breakpoints / desktop class consistent with `04_layouts/breakpoints.md`
- [ ] Spacing follows tokens / `04_layouts/spacing.md`

---

## Tokens & Components

- [ ] Colors / type / radius / shadow reference approved tokens (or listed gaps)
- [ ] No unexplained one-off styles
- [ ] Shared components follow `03_components/` contracts where defined

---

## Canonical Artifact

- [ ] Companion markdown exists under `05_canonical/desktop/`
- [ ] Export present under `07_exports/desktop/` (when visual freeze includes export)
- [ ] Export naming follows `07_exports/export_rule.md`

---

## Product Fit

- [ ] No accidental redesign of unrelated surfaces
- [ ] Content hierarchy remains analysis-first and readable
- [ ] Brand / chrome consistent with principles in `00_design_principles/`
