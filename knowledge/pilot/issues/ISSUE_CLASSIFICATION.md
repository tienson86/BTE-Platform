# Issue Classification

Version: 1.0.0

| Class | Use when |
|-------|----------|
| Defect | Product behaves incorrectly vs frozen intent |
| UX | Discoverability / hierarchy / wording friction |
| Interpretation | Report narrative credibility |
| Knowledge | Articles, links, term coverage |
| Performance | Wait time, timeouts |
| Data | Bad input or timezone, not engine “wrong school” |
| Security | Authz, leak, unsafe share |
| Commercial | License, access, pricing questions |
| Support | How-to, access provisioning |
| Feature | New capability |
| Change request | Formal ask to alter freeze surface |

One primary class per ID. Secondary tags allowed.
