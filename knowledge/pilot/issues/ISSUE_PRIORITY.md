# Issue Priority

Version: 1.0.0  
Sprint: Beta-5

| Priority | Name | Meaning |
|----------|------|---------|
| **P0** | Critical | Stop phase expansion. Security, data loss, core journey down. |
| **P1** | High | Core journey badly impaired; fix or signed waiver before next phase. |
| **P2** | Medium | Workaround exists; schedule if freeze-safe. |
| **P3** | Low | Polish, later roadmap. |

| Priority | Triage | First update to reporter |
|----------|--------|--------------------------|
| P0 | 4 hours (business or on-call) | Same day |

| P2 | Next weekly triage | 1 week |
| P3 | Monthly / phase review | On close or phase end |

Resolution time is **not** guaranteed; freeze may defer code. Support SLA placeholders remain in commercial pack (unchanged).
