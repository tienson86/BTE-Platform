# Issue Triage

Version: 1.0.0

## Cadence

Daily in Phase 1; 2–3×/week in Phase 2–3; weekly in Phase 4 plus P0 interrupt.

## Attendees

Pilot Coordinator, Product Owner (or delegate), Engineering. Support joins from Phase 3.

## Steps

1. New IDs since last meeting  
2. Confirm class + severity + priority  
3. Reproduce?  
4. Freeze-safe fix vs CR vs wontfix vs duplicate  
5. Owner + next status  
6. Phase-gate impact  

## Output

Updated board + list of P0/P1 for governance.
