# Pilot RC Checklist

Version: 1.0.0

Before inviting the next phase onto a build:

- [ ] `/version` recorded  
- [ ] Smoke: landing, create, wait, report  
- [ ] No known P0 on this build  
- [ ] Release Manager confirms **no** unplanned deploy/API/UI/engine diff vs freeze  
- [ ] Feedback channel live  
- [ ] Support knows the phase  
- [ ] Rollback tag known (existing deployment docs)

This checklist does not create a new RC engineering pipeline.
