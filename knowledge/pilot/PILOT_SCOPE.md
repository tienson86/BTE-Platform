# Pilot Scope

Version: 1.0.0  
Sprint: Beta-5

## In scope

- Product journeys listed in `internal/USER_JOURNEYS.md`
- Feedback collection via `feedback/` templates
- Moderated and unmoderated sessions (`sessions/`)
- Issue triage and change-request **process** (no automatic code change)
- Success / quality / usability / completion / adoption / business metric **definitions**
- Go / No-Go for leaving each phase and for commercial pilot

## Environments

Use the already deployed beta/production-like host. This sprint does **not** change deployment.

## People

Internal staff, invited BaZi / Feng Shui consultants, invited customers. See `participants/`.

## Explicitly out of scope

- Modifying engines, pipelines, Knowledge packages, Product UI, APIs  
- Implementing analytics, NPS widgets, or new endpoints  
- Publishing production prices  
- Expanding AF-1  

## Data

Prefer fictional or authorized birth data. No scraping of third-party client files without consent (`participants/CONSENT_TEMPLATE.md`).
