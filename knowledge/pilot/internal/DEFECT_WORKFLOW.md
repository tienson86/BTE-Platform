# Defect Workflow

Version: 1.0.0  
Sprint: Beta-5

```
Report (template) → Triage → Reproduce → Classify → Prioritize → Resolve or CR → Verify → Close
```

1. File via `feedback/BUG_REPORT_TEMPLATE.md` (or right typed template).  
2. Weekly (or daily in Phase 1) `issues/ISSUE_TRIAGE.md`.  
3. Engineering reproduces on frozen build.  
4. If freeze-safe fix: schedule; if engine/UI redesign: `CHANGE_REQUEST_PROCESS.md` → usually roadmap.  
5. Reporter or coordinator verifies.  
6. Status: new → triage → accepted → in progress → resolved → verified → closed (or wontfix / duplicate).

Every item keeps: **ID, Priority, Severity, Status, Owner, Resolution.**
