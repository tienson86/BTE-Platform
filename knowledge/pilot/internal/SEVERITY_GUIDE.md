# Severity Guide

Version: 1.0.0  
Sprint: Beta-5

Severity = user/system impact. Priority = when we act (`issues/ISSUE_PRIORITY.md`).

| Severity | Meaning | Example |
|----------|---------|---------|
| S0 / Critical | Data loss, security, total blocker | All analysis fail; PII leak |
| S1 High | Core journey blocked for many | Cannot open any report |
| S2 Medium | Workaround exists | Knowledge link 404 for one term |
| S3 Low | Cosmetic / copy | Minor spacing; typo |

Interpretation disagreement among schools is **not** automatically S0. Classify as Knowledge/Report feedback unless the UI shows the wrong person’s data.
