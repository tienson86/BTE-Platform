# Pilot Communication Plan

Version: 1.0.0  
Sprint: Beta-5

## Internal

Weekly summary: active phase, open P0/P1, sessions completed, next gate date. Owner: Pilot Coordinator.

## Participants

| Moment | Message |
|--------|---------|
| Invite | Purpose, time ask, confidentiality |
| Consent | `participants/CONSENT_TEMPLATE.md` |
| Kickoff | Expectations + how to send feedback |
| During | Reminder of one channel for bugs |
| Close | Thank-you + optional survey |
| Incident | Honest, no stack traces |

## External / marketing

Do not announce Phase 3/4 as general availability. Use “invited pilot” language. Align with `knowledge/commercial/release/COMMUNICATION_PLAN.md` without editing it.

## Channels

Email + ticket/feedback forms. Avoid unstructured group chats as the only record.
