# CASE-0001 - Nguyễn Tiến Sơn

## Purpose

First Pilot Golden Case for validating BTE v1.0-beta against a real user-provided chart.

This case records expected data separately from actual engine output. Expected values are limited to user-confirmed inputs and independently checkable BaZi table values. Interpretive outputs are not promoted to expected until expert review.

## Input

- Name: Nguyễn Tiến Sơn
- Gender: Nam
- Solar birth: 21/01/1987, 04:30
- Birth place: Hà Nội
- Timezone: Asia/Ho_Chi_Minh
- User-confirmed lunar date: 22/12/1986
- User-confirmed four pillars: Bính Dần / Tân Sửu / Canh Ngọ / Mậu Dần

## Harness

Selected runtime path:

```text
applications.api.services.orchestrator.OrchestratorService.analyze
```

Reason:

- It is the current production-aligned orchestration entrypoint.
- It runs Calendar -> BaZi -> Pattern -> Score -> Interpretation -> Report -> Narrative.
- It is used by API-facing tests and keeps the frozen engine/Knowledge architecture intact.

Command shape:

```text
OrchestratorService().analyze(
    year=1987,
    month=1,
    day=21,
    hour=4,
    minute=30,
    gender="male",
    timezone="Asia/Ho_Chi_Minh",
)
```

## Result

Status: **WARNING**

Calendar and BaZi pass against the user-confirmed input:

- Lunar date: 22/12/Bính Dần
- Four pillars: Bính Dần / Tân Sửu / Canh Ngọ / Mậu Dần
- Day master: Canh Kim, Dương

Pipeline ran through:

```text
calendar -> bazi -> pattern -> score -> interpretation -> report -> narrative
```

The case is not fully golden yet because later-stage outputs need expert review and contain consistency warnings. See `diff.md`.
