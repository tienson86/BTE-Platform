# Completion Metrics

Version: 1.0.0

Funnel (manual):

```
Started landing
  → Started create
    → Submit success
      → Wait success
        → Opened report
          → Reading completion
            → Knowledge (optional)
              → Save / PDF / share (optional)
                → History
                  → Return
```

Record N at each step per phase. Drop-off between wait and report is a stop-the-line candidate if large.
