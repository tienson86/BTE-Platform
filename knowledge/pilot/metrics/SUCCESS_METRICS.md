# Success Metrics

Version: 1.0.0  
Sprint: Beta-5  
**No analytics implementation.** Collect via session reports, surveys, and manual counts.

| Metric | Definition | Default target (planning) |
|--------|------------|---------------------------|
| Completion rate | Finished J2–J4 among those who started J2 | Phase 3 ≥ 70% |
| Reading completion | Reached overview + ≥1 main section | Phase 3 ≥ 60% |
| Knowledge CTR | Opened Knowledge from report / completed reports | Observe; no hard fail |
| Save rate | Saved case or equivalent | Observe |
| PDF export rate | Successful PDF / those who tried (or N/A) | Observe |
| Return rate | Came back within 14 days (Phase 3–4) | Observe |
| Support rate | Tickets / active participants / week | Phase 3 < 30% needing S1 help |
| Satisfaction | Survey Q9 mean | ≥ 4.0 / 5 among completers |
| NPS | Placeholder only | `NPS_PLACEHOLDER.md` |

Phase 1–2 use the same definitions with smaller N; do not overfit.
