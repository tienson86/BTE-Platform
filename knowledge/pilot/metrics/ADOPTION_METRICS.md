# Adoption Metrics

Version: 1.0.0

| Metric | Definition |
|--------|------------|
| Activated | Completed ≥1 report |
| Engaged | ≥2 sessions or return within 14 days |
| Knowledge adopted | ≥1 Knowledge open among activated |
| History adopted | ≥1 reopen |
| Champion | Expert who completes session + would demo to a peer |

Phase 4 watches activated → engaged. Small N: treat as directional.
