# Participant Expectations

Version: 1.0.0  
Sprint: Beta-5

## We ask

- Complete assigned journeys or say where you stopped  
- File feedback with the right template  
- One primary question per analysis when testing report reading  
- Reasonable response time to coordinator pings  

## Time ask (indicative)

| Phase | Per person |
|-------|------------|
| Internal | 4–8 hours over 2 weeks |
| Expert | 2–4 hours + one optional moderated session |
| Customer | 45–90 minutes + survey |
| Commercial pilot | Normal work usage + issues as they occur |

## We provide

Access, Quick Start pointer, feedback channel, a human coordinator. We do **not** provide custom engine rules or production pricing in-repo.

## We will not

Shame “wrong” traditional schools. Demand public testimonials.
