# Confidentiality Guide

Version: 1.0.0  
Sprint: Beta-5

## Participants

Do not post unreleased screens, defect lists, or other participants’ charts on social media. Do not share invite links publicly.

## Staff

No customer PII in public tickets or marketing. Session recordings stored only if consented; retention per counsel-approved policy.

## Experts

Professional courtesy: do not use another expert’s pilot charts in public teaching without permission.

## Incidents

Suspected leak → Pilot Coordinator + Product Owner; security path if needed (commercial security disclosure template — do not edit that file here).
