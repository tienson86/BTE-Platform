# Pilot Program

Version: 1.0.0  
Sprint: Beta-5

BTE Product v1.0 enters market through a **controlled pilot**, not an unbounded public launch.

## Purpose

Prove that real users can complete the consultant journey — create analysis, wait, read report, use Knowledge, save/share/history, return — with acceptable quality, support load, and no AF-1 breakage.

## Principles

- Freeze first: no engine, pipeline, Knowledge package, API, or UI redesign during pilot execution unless a P0 forces a gated exception (`issues/CHANGE_REQUEST_PROCESS.md`).
- Learn in layers: internal → expert → customer → commercial.
- Every finding has an ID, severity, priority, owner, status, and resolution.
- Metrics are defined here; analytics are **not** implemented in this sprint.

## Related commercial / ops (read-only)

Customer guides: `knowledge/commercial/customer/`  
Support: `knowledge/commercial/support/`  
Ops runbooks: `applications/runbooks/`  

This sprint must not modify those trees.
