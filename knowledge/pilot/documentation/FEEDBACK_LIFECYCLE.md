# Feedback Lifecycle

Version: 1.0.0

```
Capture (template)
  → ID assigned
    → Triage (class, severity, priority, owner)
      → Act (fix freeze-safe / CR / roadmap / wontfix)
        → Resolve + resolution text
          → Verify
            → Close
              → Optional survey / follow-up
```

Every state change keeps **ID, Priority, Severity, Status, Owner, Resolution**.

Participants see status only via coordinator follow-up, not a new in-app portal (not built here).
