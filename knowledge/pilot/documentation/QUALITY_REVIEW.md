# Quality Review

Version: 1.0.0

At each gate, Product Owner + Engineering review:

- P0/P1 list  
- Escape defects  
- Journey N/A rate (hidden scope gaps)  
- Interpretation vs data-entry mix  
- Whether any “fix” would violate AF-1  

Output feeds go / no-go. Quality review is not a redesign workshop.
