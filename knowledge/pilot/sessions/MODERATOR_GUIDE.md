# Moderator Guide

Version: 1.0.0  
Sprint: Beta-5

## Stance

Patient consultant tone. You are not selling during the task. You are watching whether the product teaches itself.

## Do

- State the task (“Start an analysis for this fictional person”).  
- Stay quiet while they work.  
- Ask “what are you looking for?” after a stall.  
- Stop a task that risks real PII.

## Do not

- Click for them.  
- Defend the engine.  
- Promise a Knowledge package edit this week.  
- Argue schools.

## Timebox

Landing + create + wait + read overview: 25 minutes core. Knowledge/PDF/history if time.
