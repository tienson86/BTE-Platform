# Pilot Governance

Version: 1.0.0  
Sprint: Beta-5

Responsibilities only. No new org chart tooling.

| Role | Responsibility |
|------|----------------|
| **Product Owner** | Scope, priority of change requests, go / no-go vote, roadmap input |
| **Pilot Coordinator** | Recruitment, schedule, consent, session logistics, metric collection (manual) |
| **Engineering** | Reproduce defects, estimate freeze-safe fixes, refuse out-of-scope engine work |
| **Support** | Intake during Phases 3–4, SLA placeholders, customer tone |
| **Consultant (advisor)** | Expert-pilot interpretation credibility, report-reading sanity |
| **Release Manager** | RC checklist, environment identity, rollback readiness (using existing deployment docs) |

## Decision rights

- P0/P1 ship-block: Product Owner + Engineering + Release Manager  
- Phase expansion: Product Owner + Pilot Coordinator  
- AF-1 exception: not granted in pilot; defer to a future major version  

## Cadence artifacts

Triage log, session reports, go/no-go minutes (`releases/GO_NO_GO_DECISION.md`).
