This folder is the **Beta Cycle 1** planning surface.

Beta1 may repair defects, editorial admission, knowledge-record quality, engine correctness inside frozen owners, and consultation readability.

Beta1 may not add engines, frameworks, matrices, publishers, composers, canons, layers, runtime components, or new commercial capabilities.

Do not start Luck Domain, Temperature Domain, Story Engine, or Case Identity Engine in this cycle.
