# Release Candidate

| Field | Value |
|-------|-------|
| Stage | **RC** |
| Meaning | Candidate for Production 1.0 (RC1, RC2, …) |
| Sold | No |
| Feature development | No. Defect and admission only. |

This folder holds signed records for Release Candidates.

RC opens only when Product Owner judges Beta quality sufficient to candidate 1.0.
RC requires Editorial PASS, Commercial PASS, Product Owner approval, and Customer Pilot / human consulting review as Product policy states.

A failed RC is retained.
The next candidate is RC2, not a reused RC1.

Until a version subfolder is opened, this stage has **no issue records**.

Historical Commercial V1 RC packages remain in `knowledge/releases/v1/` and `knowledge/product/release_candidate/`.
They do not substitute for a signed issue in this folder.
