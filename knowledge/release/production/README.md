# Production

| Field | Value |
|-------|-------|
| Stage | **Production** |
| Meaning | Sold consultation versions (1.0, 1.0.x, 1.1, …) |
| Sold | Yes, after signoff |
| Feature development | Only if Product Owner opened a Production minor (for example 1.1). Patches are repair. |

This folder holds signed Production issues, including Emergency Patch and Hotfix records that issued a Production patch version.

Production does not begin on a calendar date.
Production begins when RC gates pass and Product Owner signs.

Until a version subfolder is opened, this stage has **no issue records**.
No 1.0 exists until that record is signed.
