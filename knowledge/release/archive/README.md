# Archive

| Field | Value |
|-------|-------|
| Stage | **Archive** |
| Meaning | Superseded or withdrawn issue records |
| Sold | No |

This folder retains release records that must not be treated as current:

- withdrawn versions after rollback
- superseded candidates
- freeze errata replaced by a later signed record

Archive is retention, not deletion.
Do not reissue archived artifacts.
Do not reuse withdrawn version names.

Until a record is moved here, this stage has **no archived issues**.
