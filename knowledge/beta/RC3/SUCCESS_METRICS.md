# SUCCESS_METRICS

| Field | Value |
|-------|-------|
| Program | RC3 Internal Beta |
| Gate | Minimum acceptance to **close RC3** and consider Commercial V1 planning |

RC3 success is customer discovery quality — not a public launch stamp.

---

## Minimum acceptance (all required)

| # | Criterion | Floor |
|---|-----------|-------|
| S1 | Completed forms | **10 / 10** personas (one each) |
| S2 | Bound real charts | **10** (0001–0003 already; 0004–0010 bound before close) |
| S3 | Trust mean (cohort) | **≥ 7.0** |
| S4 | Clarity mean | **≥ 7.0** |
| S5 | Value mean | **≥ 7.0** |
| S6 | Actionability mean | **≥ 7.0** |
| S7 | Recommendation = Yes | **≥ 7 / 10** cases (or score mean ≥ 7.0) |
| S8 | Purchase Intent = Yes | **≥ 6 / 10** cases (or score mean ≥ 7.0) |
| S9 | Child/parent (P03) | Trust ≥ 7 · Career hidden · no adult work-week as primary ask |
| S10 | CASE_0001 | No S0/S1 from P01 that contradicts Frozen Golden without Product review |
| S11 | Open S0 from beta | **0** unwaived |
| S12 | Open S1 from beta | **0** unwaived (or Product waiver + expiry) |
| S13 | Golden regression | CASE_0001 still PASS if any later change is proposed |

A single P03 Context FAIL (adult Career to a parent) **fails RC3** regardless of adult means.

---

## Soft targets (do not block close if S1–S13 hold)

| Target | Aim |
|--------|-----|
| “What felt generic?” empty or S3-only | ≥ 6 / 10 cases |
| “Would pay” with package named | ≥ 5 / 10 |
| P09 honesty | No invented UG/facts |

---

## Outcomes

| Result | Meaning |
|--------|---------|
| RC3 PASS | Discovery complete; Product may plan Commercial V1 |
| RC3 HOLD | Missing charts, floors, or unwaived S0/S1 |
| RC3 FAIL | P03 unsafe or Golden contradicted |

PASS ≠ permission to sell to strangers. That remains Commercial V1 Product sign-off.
