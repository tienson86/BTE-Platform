# HYPOTHESES

| Field | Value |
|-------|-------|
| Rule | Product hypotheses only |
| Forbidden | New architecture · Persona Engine · engine/Knowledge edits |

Each hypothesis is testable on the next frozen run. None requires a new subsystem.

---

## H1 — Delivery quality tracks theme, not persona

If CDR `primary_theme` already names the buyer’s job (output, self-carry), adult pass_through is enough.

**Support:** P05 MET 8.0 on OPERATING_OUTPUT. P02 already MET on the same theme.  
**Counter:** P04/P06 still need a human-shaped close when theme ≠ need.

## H2 — Adult pass_through is the recurring miss — but only when theme and need diverge

Child/parent already has adaptive delivery (P03 / EPIC-B). Adults do not.

**Support:** P04 and P06 both pass_through and both miss. P05 pass_through and hits because theme did the work.  
**Not claimed:** Every adult needs a persona pack.

## H3 — P02 and P05 are one commercial class

“Output Maker” and “Special-structure Seeker” are two marketing names for OPERATING_OUTPUT + non-ordinary frame.

**Support:** P05 copy already says “khuôn chung / khung riêng / đầu ra” — P02’s language.  
**Implication:** Do not split them into two engines.

## H4 — Dual-scope boilerplate is not tension delivery

The line “Trước khi chốt một nhãn duy nhất” appears in P04, P05, and P06. Only P05 then keeps a *lived* second frame (khung riêng). P06 still closes on one label (tự gánh). P04 uses it as empty dual-layer jargon.

**Support:** Same sentence, three meanings, two failures.  
**Implication:** Tension = keep two published stories in the close, not a disclaimer.

## H5 — Empty “khung lá số” means structure was not mapped to a customer phrase

P04 and P06 emit “khung dài hạn đã xác định trong lá số.”  
P05 emits “khung dài hạn kiểu riêng” because Tòng is already a phrase.

**Implication:** Composer gap on non-follow structures — not a persona taxonomy.

## H6 — Memory lines leak across themes

“Vòng ra kết quả”, “sản phẩm nhìn thấy”, “Bạn mạnh hơn khi…” travel into BALANCE_DIRECTION (P04) and SELF_CARRY (P06).

**Implication:** Theme-gated memory, not a Persona Engine.

## H7 — Conservation is a capacity/theme job, not a persona job

P04 failed because `body:balanced` + pass_through + “mạnh hơn”.  
P03 already conserves for **child** via Product Context.

**Implication:** Adult conservation = extend existing context/capacity path. Do not invent “Conserving Adult Engine.”

## H8 — A Persona Engine would duplicate what already routes

Routing today:

```text
CDR theme + identity_core
    → CLL / composer
    → Product Context (life stage / reader)
    → adult pass_through or parent adaptive
```

Ten named personas would sit *beside* this and fight it.

**Implication:** Persona Engine V2 is not justified (see NEXT_DECISION).
