# KNOWLEDGE RECORD EXAMPLE

**Canonical Example**

Version: 1.0.0

---

# Purpose

This document demonstrates the correct use of the Knowledge Record Template.

Every new Knowledge Record SHOULD follow the structure and style illustrated in this example.

This example serves as the reference implementation for authors, reviewers, validators, and compiler developers.

---

# Selected Example

Knowledge Record:

Yin Yang (Âm Dương)

Reason for Selection:

- Foundational concept
- Used across multiple domains
- Rich relationship network
- Suitable for demonstrating all template sections

# Example Structure

The example SHALL include every section defined in:

KNOWLEDGE_RECORD_TEMPLATE.md

including:

- Identity
- Classification
- Academic Sources
- Scope
- Canonical Definition
- Characteristics
- Relationships
- Constraints
- Examples
- References
- Metadata
- Computational Semantics
- Explainability
- Validation
- Revision History
- Compiler Hints
- Quality Metrics

---

# Writing Guidelines

The example SHALL:

- use real academic content
- cite authoritative references
- demonstrate complete metadata
- demonstrate relationship modeling
- demonstrate explainability
- demonstrate compiler readiness

The example SHALL NOT:

- omit mandatory sections
- use placeholder values
- contain fictional knowledge
- include implementation logic
