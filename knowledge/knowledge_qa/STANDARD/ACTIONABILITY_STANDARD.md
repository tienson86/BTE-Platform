# Actionability Standard — V1.0

| Field | Value |
|-------|-------|
| Document | ACTIONABILITY_STANDARD |
| Standard | Knowledge QA V1.0 |

---

# 1. Purpose

Advice must connect **fact → interpretation → action**.

Description alone is insufficient for ADVANTAGE and RECOMMENDATION units.

---

# 2. Frozen chain

```text
Published Fact
  ↓
Interpretation (claim)
  ↓
Action (do / protect / choose / avoid)
```

---

# 3. Rules by topic

| Topic | Actionability expectation |
|-------|---------------------------|
| MEANING | Descriptive OK; score ≥ 6 |
| CAUSES | Explain why; action optional |
| ADVANTAGES | Must imply use; score ≥ 7 |
| CHALLENGES | Must imply cost awareness; score ≥ 7 |
| RECOMMENDATION | Must steer; score ≥ 7 or FAIL |
| PERSONALITY | Behavioral insight OK; score ≥ 6 |
| LUCK | Timing awareness; score ≥ 7 if advisory |

---

# 4. Evaluation

Ask:

1. What fact triggered this?
2. What does customer understand now?
3. What should they **do** differently?

If step 3 has no answer → REVIEW (ADV/REC) or lower score.

---

# 5. Typical failures

| Unit type | Failure |
|-----------|---------|
| ADVANTAGE | “Has endurance” with no use context |
| RECOMMENDATION | Generic “balance work and rest” without link to challenge |
| ADVANTAGE | Restates MEANING identity only |

PACK-01: ADV-0009 PASS (endurance as proof of capacity); ADV generic balanced facet REVIEW when no steer.
