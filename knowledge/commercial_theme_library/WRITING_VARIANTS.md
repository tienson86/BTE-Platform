Variant is dress. Theme is class. CLL still owns grammar.

---

## Variants

| Id | When | Cadence |
|----|------|---------|
| **formal** | Default Package B/C | Full sections, calm consultant |
| **warm** | High recognition, still paid advice | Same facts, closer address |
| **premium** | Executive / Package C close | Shorter, higher density, no soft filler |
| **short** | Share card / Identity Summary | One beat per block max |

Product Context may pick variant. This library does not invent a fifth voice.

---

## Rules

1. Variant must not change class (CONSERVING short ≠ “cố lên”).  
2. Premium is not colder Truth — it is less padding.  
3. Short still answers So what.  
4. No English slang in Vietnamese customer bodies.  
5. If CONSERVING overlay is on, **all four** variants forbid “bạn mạnh hơn khi…”.
