## Purpose

Give the Commercial Language Layer a **reusable theme catalog**:

what kind of consulting this chart is,  
what blocks to write,  
in which writing variant —  
without inventing facts and without case-specific copy.

```
CDR themes + capacity + structure  (Truth — frozen, read-only)
        ↓
Commercial Theme Library V1.0      (this package)
        ↓
Commercial Language Layer          (how paragraphs are written — not modified here)
        ↓
Identity / Career / Executive
```
