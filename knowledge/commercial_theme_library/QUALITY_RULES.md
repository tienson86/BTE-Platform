# QUALITY_RULES

| Field | Value |
|-------|-------|
| Package | Commercial Theme Library V1.0 |

---

## Must

1. **Reusable** — any chart with the same published signals can use the same stance.  
2. **No CASE-specific wording** — no birth dates, no “như case kia.”  
3. **No hard-coded names** — no personal names in the catalog.  
4. **No new Truth** — stances rephrase published class; they do not add gods, luck, income, diagnoses.  
5. **Theme-gated Memory** — Memory of theme A must not leak into theme B.  
6. **Overlay wins the close** — CONSERVING / TENSION_HOLDER / FOLLOW_FRAME gate Memory + Action when bound.  
7. **One Memory per deliverable** (unless a section is sold alone).  
8. **Vietnamese customer bodies** — ids may be English; stances are consulting Vietnamese or bilingual intent.

---

## Must not

| Forbidden | Why |
|-----------|-----|
| Persona Engine | Discovery decision: personas are lenses |
| “Khung đã xác định trong lá số” | Empty; not a structure phrase |
| Job titles, salary, luck windows | CLL + product ethics |
| Ordinary-mold lecture on FOLLOW_FRAME | P05 class |
| Empowerment close on CONSERVING | P04 class |
| Single-label close on TENSION_HOLDER | P06 class |
| Copy CASE-0001 master into another theme | Overfit |

---

## Review questions (per block)

- Would this still be true for a *different* person in the same class?  
- Can I remove every proper noun and keep the line?  
- Does CONSERVING still conserve in Short?  
- Did I import output-cycle language into a non-output theme?

If any fail → rewrite the stance, not the chart.
