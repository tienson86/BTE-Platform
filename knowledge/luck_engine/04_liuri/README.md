# LiuRi Module (流日)

## Overview

The LiuRi Module is responsible for calculating and evaluating Daily Luck (流日) within the BTE Platform.

A LiuRi represents the energetic influence of one Sexagenary Day (干支日) on an individual's BaZi chart.

Unlike conventional calendar systems, LiuRi is determined using the Sexagenary Day Cycle (六十甲子) generated by the Calendar Engine.

The module evaluates how the Daily Pillar interacts with:

- Natal Chart (命局)
- Current Dayun (大运)
- Current LiuNian (流年)
- Current LiuYue (流月)
- Hidden Heavenly Stems
- Ten Gods
- Five Elements
- Combination Rules
- Clash Rules
- Transformation Rules
- Priority Rules

The result is a structured Daily Context consumed by downstream engines.

The module is responsible for
