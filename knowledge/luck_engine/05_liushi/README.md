# LiuShi Module (流时)

## Overview

The LiuShi Module is responsible for calculating and evaluating Hourly Luck (流时) within the BTE Platform.

A LiuShi represents the energetic influence of one Sexagenary Hour (干支时) on an individual's BaZi chart.

The Hourly Pillar is generated by the Calendar Engine using the current Sexagenary Day together with the traditional Twelve Double-Hour (十二时辰) system.

The module evaluates how the Hourly Pillar interacts with:

- Natal Chart (命局)
- Current Dayun (大运)
- Current LiuNian (流年)
- Current LiuYue (流月)
- Current LiuRi (流日)
- Hidden Heavenly Stems
- Ten Gods
- Five Elements
- Combination Rules
- Clash Rules
- Transformation Rules
- Priority Rules

The result is a structured Hourly Context consumed by higher-level engines.

# Hour Boundary

The Hourly Pillar SHALL follow the configured Hour Boundary Policy provided by the Calendar Engine.

The module SHALL NOT calculate hour boundaries independently.

Supported policies include

- Traditional Twelve Double-Hour System
- Timezone-aware Hour Boundary
- Configurable Calendar Policy
