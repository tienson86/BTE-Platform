# Unified Timeline Module

## Overview

The Unified Timeline Module is responsible for combining every Fortune Context generated by the BTE Platform into a single normalized Timeline Context.

Unlike previous Fortune Engine modules, this module performs no fortune calculation.

Instead, it aggregates and synchronizes previously generated contexts.

The Unified Timeline becomes the single source of truth consumed by downstream engines.

The module combines

- Natal Chart
- Dayun Context
- LiuNian Context
- LiuYue Context
- LiuRi Context
- LiuShi Context

into one immutable Timeline Context.

---

# Responsibilities

The module is responsible for

- Loading every Fortune Context
- Validating all Contexts
- Synchronizing Timeline Layers
- Resolving Context References
- Merging Metadata
- Constructing Timeline Context
- Producing immutable Timeline Objects

The module SHALL NOT

- Calculate BaZi
- Generate Pillars
- Calculate Ten Gods
- Evaluate Transformations
- Resolve Priorities
- Produce Interpretation
