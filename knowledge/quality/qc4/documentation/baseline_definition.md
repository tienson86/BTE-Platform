# Baseline definition

Baseline methodology: pin platform, Foundation, knowledge, schema, pipeline, engine, and AF-1 package versions from frozen indexes; pin ecosystem package count from QC-1; pin snapshot counts from QC-2; pin handoff status from QC-3.

Identifier `BSL-QC4-1.0.0` is the quality baseline for v1.x RC. It does not replace `BTE-ARCH-CERT-1.0.0`.
