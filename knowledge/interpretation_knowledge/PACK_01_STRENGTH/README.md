# 1. Purpose

This pack is the **what to say** knowledge for Day Master Strength.

It describes what a professional BaZi consultant would explain about:

- Very Strong (Thân Cực Vượng)
- Strong (Thân Vượng)
- Balanced (Trung Hòa)
- Weak (Thân Nhược)
- Very Weak (Thân Cực Nhược)

It is domain knowledge for lived life.

It is not a scoring method.

It is not a rule list.

It is not the Interpretation Standard.

---

# 2. Division of Labor

| Layer | Answers |
|-------|---------|
| Strength Engine / Rule Database | What the class **is** (fact) |
| Interpretation Standard | **How** to say it (Mode A / Mode B, sentence, value, leak bans) |
| **This pack** | **What** to say (meanings, causes, life effects, advice) |
| Future Interpretation Engine | Selects and composes knowledge units |
| Report Engine | Layout and export |

Do not mix these jobs.

---

# 4. Knowledge Style

Professional. Natural. Practical. Commercial. Readable.

Every paragraph must create value.

Every section must answer **So what?**

Never define terms like a dictionary.

Always explain what the standing means in real life.

Strong is not morally better than Weak.

Weak is not misfortune.

Balanced is not “no personality”.
