# Base Components (WP02)

| Component | Props | Example |
|-----------|-------|---------|
| Button | ButtonProps | `<Button variant="primary">Save</Button>` |
| IconButton | IconButtonProps | `<IconButton label="Close" icon={...} />` |
| Card | CardProps | `<Card title="Title">Body</Card>` |
| Divider | DividerProps | `<Divider />` |
| Badge | BadgeProps | `<Badge>New</Badge>` |
| Tag | TagProps | `<Tag>Water</Tag>` |
| Avatar | AvatarProps | `<Avatar name="A" />` |
| Chip | ChipProps | `<Chip>Filter</Chip>` |

Underlying `Base*` primitives remain for backward compatibility.
