# Runbooks

Version: 1.0.0  
Sprint: Beta-3

Operator procedures. They do not change engines, pipelines, or product UI.

| Runbook | Use when |
|---------|----------|
| `API_INCIDENT.md` | API unavailable or unhealthy |
| `PORTAL_INCIDENT.md` | Portal unavailable |
| `DEPLOYMENT_FAILURE.md` | Deploy/rollback failed |
| `BACKUP_FAILURE.md` | Backup job failed |
| `HIGH_LATENCY.md` | p95 latency breach |
| `HIGH_MEMORY.md` | Memory exhaustion |
| `DISK_FULL.md` | Disk / volume full |
| `DATABASE_RECOVERY.md` | Restore / storage recovery |
| `SERVICE_RESTART.md` | Planned or emergency restart |
| `MAINTENANCE_WINDOW.md` | Routine maintenance + cert renewal |

Deployment commands: `deployment/OPERATIONS_RUNBOOK.md` (unchanged).
