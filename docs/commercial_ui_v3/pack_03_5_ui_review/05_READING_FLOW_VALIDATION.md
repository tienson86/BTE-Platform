# 1. PURPOSE

This document defines
the official Reading Flow Validation
for Commercial UI V3.

Commercial UI V3
is evaluated by

user understanding,

not visual appearance alone.

The objective is to verify

whether users receive
the intended knowledge
at every stage
of the reading journey.

------------------------------------------------------------------------------

# 2. DESIGN PHILOSOPHY

Commercial UI V3 is

a consultation report.

Readers move through

Understanding

↓

Explanation

↓

Evidence

↓

Decision

↓

Confidence

Validation measures

knowledge acquisition,

not interaction count.

------------------------------------------------------------------------------

# 3. READING JOURNEY

Every reader
passes through
seven stages.

Executive Hero

↓

Four Pillars

↓

Executive Insight

↓

Visual Analytics

↓

Explainable Analysis

↓

Consultation Report

↓

Knowledge Workspace

Every stage
must answer
a different question.

------------------------------------------------------------------------------

# 4. STAGE 1

EXECUTIVE HERO

Expected Reading Time

5–10 seconds

The user must understand

✓ Who am I?

✓ Overall Chart Quality

✓ Primary Recommendation

The user should

NOT

need to scroll.

PASS

Three questions answered.

FAIL

User still uncertain
about chart status.

------------------------------------------------------------------------------

# 5. STAGE 2

FOUR PILLARS

Expected Reading Time

20–40 seconds

The user must understand

✓ Four Pillars structure

✓ Day Master

✓ Hidden Stems

✓ Main relationships

The section should

explain structure,

not interpretation.

PASS

User identifies
all four pillars.

FAIL

User cannot distinguish
the Day Pillar.

------------------------------------------------------------------------------

# 6. STAGE 3

EXECUTIVE INSIGHT

Expected Reading Time

30–60 seconds

The user must understand

✓ Major Strengths

✓ Major Weaknesses

✓ Opportunities

✓ Risks

✓ Immediate Recommendation

The section answers

"What should I remember?"

PASS

User summarizes
the key conclusions.

FAIL

User only recalls
isolated facts.

------------------------------------------------------------------------------

# 7. STAGE 4

VISUAL ANALYTICS

Expected Reading Time

30–60 seconds

The user must understand

✓ Element Balance

✓ Strength Level

✓ Ten Gods Distribution

Charts

support

the written insight.

Charts
must never become
the main focus.

PASS

Charts reinforce conclusions.

FAIL

User studies charts
without understanding
their meaning.

------------------------------------------------------------------------------

# 8. STAGE 5

EXPLAINABLE ANALYSIS

Expected Reading Time

2–5 minutes

The user must understand

✓ Why

the system reached
its conclusions.

Each Analysis Block
must follow

Conclusion

↓

Explanation

↓

Evidence

↓

Rule

↓

Confidence

↓

Knowledge

PASS

User explains

why

the conclusion exists.

FAIL

User accepts conclusion
without understanding.

------------------------------------------------------------------------------

# 9. STAGE 6

CONSULTATION REPORT

Expected Reading Time

5–15 minutes

The user should gain

deep understanding
of the chart.

Every chapter

adds meaning.

Never repetition.

PASS

Reader finishes
with coherent understanding.

FAIL

Reader experiences

duplication

or

information overload.

------------------------------------------------------------------------------

# 10. STAGE 7

KNOWLEDGE WORKSPACE

Expected Reading Time

2–10 minutes

The user verifies

Evidence

↓

Rules

↓

Classical References

↓

Confidence

↓

Related Topics

This stage

builds trust.

PASS

User can verify conclusions.

FAIL

Knowledge appears
detached from the report.

------------------------------------------------------------------------------

# 11. CROSS-STAGE VALIDATION

Every stage
must naturally lead
to the next.

Hero

creates curiosity.

↓

Pillars

provide context.

↓

Insight

creates understanding.

↓

Analytics

provides support.

↓

Analysis

explains.

↓

Report

deepens.

↓

Knowledge

validates.

If any transition
feels abrupt,

the Reading Journey fails.

------------------------------------------------------------------------------

# 12. USER QUESTIONS MATRIX

| Stage | Primary Question |
|--------|------------------|
| Hero | Who am I? |
| Four Pillars | What is my chart made of? |
| Insight | What matters most? |
| Analytics | How balanced is my chart? |
| Analysis | Why is this the conclusion? |
| Report | What does this mean for my life? |
| Knowledge | How can I verify this? |

Every question
must have a clear answer.

------------------------------------------------------------------------------

# 13. COGNITIVE LOAD

Commercial UI V3
must minimize

Mental effort.

Avoid

Multiple competing highlights.

Repeated information.

Large visual jumps.

Nested layouts.

Readers
should always know

where they are,

why they are there,

and

what comes next.

------------------------------------------------------------------------------

# 14. REVIEW CRITERIA

Reviewers evaluate

Reading Comfort

↓

Information Hierarchy

↓

Explanation Quality

↓

Evidence Traceability

↓

Decision Support

Visual aesthetics
are reviewed
after reading quality.

------------------------------------------------------------------------------

# 15. USER TEST SCENARIOS

Scenario A

First-time visitor

Goal

Understand chart quality
within 10 seconds.

--------------------------------------------------

Scenario B

Returning user

Goal

Locate one chapter
within 5 seconds.

--------------------------------------------------

Scenario C

Professional consultant

Goal

Verify evidence
for one conclusion.

--------------------------------------------------

Scenario D

Mobile user

Goal

Read recommendations
comfortably
with one hand.

------------------------------------------------------------------------------

# 16. FAILURE CONDITIONS

Reading Flow fails if

✗ Hero does not answer
the three key questions.

✗ Reading order changes.

✗ Charts dominate text.

✗ Analysis lacks evidence.

✗ Report repeats itself.

✗ Knowledge cannot validate
the report.

✗ Users become lost.

------------------------------------------------------------------------------

# 17. SUCCESS METRICS

Commercial UI V3 passes
Reading Flow Validation
only when

✓ Every stage
answers its question.

✓ Reading order
is preserved.

✓ Explanations
precede evidence.

✓ Evidence
supports conclusions.

✓ Recommendations
are actionable.

✓ Readers
finish with confidence.

------------------------------------------------------------------------------

# 18. QA EXECUTION

QA shall validate

Desktop

Tablet

Mobile

using

identical Reading Goals.

Presentation may adapt.

Meaning may not.

------------------------------------------------------------------------------

# 19. FINAL ACCEPTANCE

Commercial UI V3
passes Reading Flow Validation
only if

Users consistently describe
their experience as

"I understand my BaZi chart."

rather than

"I saw many charts and cards."

------------------------------------------------------------------------------

# 20. FREEZE

After approval,

this Reading Flow Validation
becomes the official
UX validation standard
for Commercial UI V3.

Every future UI change
must pass this validation
before release.
