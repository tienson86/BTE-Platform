# 1. PURPOSE

Icons exist to support understanding.

Icons never replace text.

Icons never replace hierarchy.

Icons never become
the primary visual element.

Commercial UI V3 is

Reading First.

Icons support reading.

------------------------------------------------------------------------------

# 2. DESIGN PHILOSOPHY

Icons should feel

Minimal

↓

Neutral

↓

Professional

↓

Timeless

↓

Consistent

Icons should never feel

Decorative

Gaming

Marketing

Illustrative

Playful

------------------------------------------------------------------------------

# 3. ICON PRINCIPLES

Commercial UI V3 follows
five icon principles.

Clarity

↓

Consistency

↓

Recognition

↓

Accessibility

↓

Subtlety

Every icon
must improve comprehension.

Otherwise

remove it.

------------------------------------------------------------------------------

# 4. ICON ROLE

Icons have exactly four roles.

Navigation

↓

Meaning

↓

Status

↓

Action

Icons never exist
only for decoration.

------------------------------------------------------------------------------

# 5. NAVIGATION ICONS

Purpose

Help orientation.

Examples

Home

Report

Analysis

Knowledge

Settings

Navigation icons

must remain visually quiet.

------------------------------------------------------------------------------

# 6. MEANING ICONS

Meaning Icons
support section titles.

Examples

Executive Summary

Analysis

Recommendation

Knowledge

Reference

Only one icon
per section.

------------------------------------------------------------------------------

# 7. STATUS ICONS

Status Icons
indicate state.

Examples

Success

Warning

Unavailable

Verified

Pending

Status icons
must always appear
with text.

Never alone.

------------------------------------------------------------------------------

# 8. ACTION ICONS

Action Icons
represent interaction.

Examples

Expand

Collapse

Copy

Share

Download

Search

Action icons
must remain secondary.

------------------------------------------------------------------------------

# 9. ICON STYLE

Commercial UI V3 uses

Simple

Outlined

Geometric

Balanced

Uniform

No 3D.

No gradients.

No emojis.

No skeuomorphic icons.

------------------------------------------------------------------------------

# 10. ICON SIZE

Commercial UI V3
defines semantic icon sizes.

icon.small

Inline metadata.

--------------------------------------------------

icon.medium

Section support.

--------------------------------------------------

icon.large

Hero only.

Raw pixel values
must never appear.

------------------------------------------------------------------------------

# 11. ICON COLOR

Icons inherit

semantic color tokens.

Examples

icon.primary

icon.secondary

icon.muted

icon.success

icon.warning

Icons never define
their own colors.

------------------------------------------------------------------------------

# 12. ICON SPACING

Icons always align
with typography.

Text

↓

Icon

↓

Whitespace

↓

Content

Icons
must never break
reading rhythm.

------------------------------------------------------------------------------

# 13. ICON ALIGNMENT

Icons align

to text baseline.

Never float.

Never misalign
between sections.

Visual consistency
is mandatory.

------------------------------------------------------------------------------

# 14. ICON & TYPOGRAPHY

Typography
always dominates.

Icons support.

If users notice icons
before headings,

hierarchy has failed.

------------------------------------------------------------------------------

# 15. ICON & COLOR

Icons inherit

semantic meaning.

Icons never introduce
new semantic colors.

Meaning belongs to

Text

+

Color

+

Context.

------------------------------------------------------------------------------

# 16. ICON ACCESSIBILITY

Icons require

Accessible labels.

Keyboard focus.

Screen reader support.

Decorative icons

must be hidden
from assistive technologies.

------------------------------------------------------------------------------

# 17. RESPONSIVE ICONS

Desktop

Standard size.

Laptop

Standard size.

Tablet

Standard size.

Mobile

Reduced spacing only.

Icon meaning
never changes.

------------------------------------------------------------------------------

# 18. ICON TOKENS

All icons
consume semantic tokens.

Examples

icon.size.small

icon.size.medium

icon.size.large

icon.color.primary

icon.color.muted

icon.spacing.inline

Components
must never
hardcode icon values.

------------------------------------------------------------------------------

# 19. IMPLEMENTATION RULES

Frontend SHALL NOT

Invent icons.

Mix icon families.

Use decorative icons.

Hardcode icon sizes.

Hardcode icon colors.

Everything
must consume
Icon Tokens.

------------------------------------------------------------------------------

# 20. ANTI-PATTERNS

Commercial UI V3
must never contain

Emoji as UI.

Mixed icon styles.

Filled and outline icons mixed.

Large decorative icons.

Icon walls.

Icons replacing text.

Animated icons.

Icons with gradients.

If users
remember icons
more than content,

the design fails.

------------------------------------------------------------------------------

# 21. ACCEPTANCE CRITERIA

Iconography passes only when

✓ Icons improve recognition.

✓ Icons never dominate.

✓ Typography remains primary.

✓ Icons remain consistent.

✓ Navigation feels intuitive.

✓ Reports remain professional.

------------------------------------------------------------------------------

# 22. FREEZE

After approval,

Iconography
becomes immutable.

Future components
must consume
Icon Tokens only.

No implementation
may bypass
this specification.
