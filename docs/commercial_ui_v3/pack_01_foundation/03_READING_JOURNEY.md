# 1. PURPOSE

The goal of BTE is NOT to present information.

The goal is to guide users through understanding.

Therefore,

Commercial UI V3 is designed as a reading journey,
not as a collection of screens.

Users should never ask:

"Where do I click next?"

Instead they should naturally continue reading.

------------------------------------------------------------------------------

# 2. READING PHILOSOPHY

The report is read exactly like a premium consultation document.

Not like software.

Not like a dashboard.

Not like documentation.

The interface should gradually disappear.

The content becomes the experience.

The software becomes invisible.

------------------------------------------------------------------------------

# 3. USER COGNITIVE STAGES

The user journey consists of six cognitive stages.

Stage 1

Recognition

↓

Stage 2

Orientation

↓

Stage 3

Understanding

↓

Stage 4

Explanation

↓

Stage 5

Consultation

↓

Stage 6

Verification

Each stage answers one primary question.

Never mix stages.

------------------------------------------------------------------------------

# 4. THE FIRST 3 SECONDS

The first viewport is the most valuable area
of the entire application.

Within three seconds the user must understand:

Who am I?

↓

Is this chart generally good or difficult?

↓

What is the first recommendation?

Nothing else should compete for attention.

No detailed rules.

No charts.

No long paragraphs.

No technical terminology.

Success Criteria

The user can summarize
their chart in one sentence
without scrolling.

------------------------------------------------------------------------------

# 5. THE FIRST 30 SECONDS

After scrolling once,
the user should understand:

The four pillars.

↓

Main strengths.

↓

Main weaknesses.

↓

Overall opportunities.

↓

Overall risks.

The goal is confidence.

Not detail.

Not explanation.

Not evidence.

------------------------------------------------------------------------------

# 6. THE FIRST 2 MINUTES

At this stage,
the user starts asking:

Why?

Commercial UI now introduces:

Explainable Analysis.

Each block follows exactly:

Conclusion

↓

Explanation

↓

Evidence

↓

Rule

↓

Confidence

↓

Knowledge

Never reverse this sequence.

------------------------------------------------------------------------------

# 7. THE FIRST 10 MINUTES

Now the user is ready
for long-form reading.

The Consultation Report
becomes the primary experience.

Readers consume:

Personality

Career

Wealth

Relationships

Health

Luck

Recommendations

The interface should feel like reading
a professional advisory report.

------------------------------------------------------------------------------

# 8. ADVANCED READING

Only after the report
does the reader enter

Appendix.

Appendix is optional.

It exists for:

Professionals.

Researchers.

Advanced users.

Curious readers.

It is NOT required
to understand the report.

------------------------------------------------------------------------------

# 9. ATTENTION FLOW

The user's eyes should naturally move:

Executive Summary

↓

Recommendation

↓

Four Pillars

↓

Executive Insight

↓

Explainable Analysis

↓

Consultation Report

↓

Appendix

Never create competing visual anchors.

There must always be one dominant focal point.

------------------------------------------------------------------------------

# 10. SCROLL RHYTHM

Scrolling should feel effortless.

Every section introduces
exactly one new idea.

The report should never feel repetitive.

Readers should feel rewarded
after each scroll.

Each new section answers
a new question.

------------------------------------------------------------------------------

# 11. READING RHYTHM

Alternate between:

Summary

↓

Detail

↓

Summary

↓

Detail

↓

Summary

↓

Evidence

This rhythm prevents fatigue.

Long analytical sections
must always be followed
by simpler reading.

------------------------------------------------------------------------------

# 12. EMOTIONAL JOURNEY

Commercial UI V3 intentionally guides emotion.

Curiosity

↓

Recognition

↓

Understanding

↓

Confidence

↓

Reflection

↓

Decision

↓

Trust

The interface must reduce anxiety.

Never increase uncertainty.

------------------------------------------------------------------------------

# 13. VISUAL PAUSES

Users require cognitive rest.

Between major chapters,
provide visual breathing room.

Do NOT fill whitespace
with additional widgets.

Whitespace is intentional.

Whitespace is content.

------------------------------------------------------------------------------

# 14. INFORMATION DISCLOSURE

Every section answers
only one level of curiosity.

Level 1

What?

↓

Level 2

Why?

↓

Level 3

How?

↓

Level 4

Evidence.

↓

Level 5

Reference.

Never reveal Level 5
before Level 1 is complete.

------------------------------------------------------------------------------

# 15. USER EXIT POINTS

Users may stop reading
at any moment.

Commercial UI V3 must ensure
they still receive value.

Exit after Hero

→ Understand chart quality.

Exit after Executive Insight

→ Understand strengths and weaknesses.

Exit after Explainable Analysis

→ Understand reasons.

Exit after Consultation Report

→ Receive complete consultation.

Exit after Appendix

→ Verify every important conclusion.

Every exit point
must feel complete.

------------------------------------------------------------------------------

# 16. ANTI-PATTERNS

Commercial UI must NEVER become:

A dashboard with many widgets.

A statistics portal.

A documentation site.

A data browser.

A debug interface.

A scrolling wall of charts.

A scrolling wall of cards.

If users begin exploring components
instead of reading the report,
the design has failed.

------------------------------------------------------------------------------

# 17. IMPLEMENTATION RULES

Frontend implementation
shall preserve
reading order.

Responsive layouts
may rearrange columns,

but

shall NEVER rearrange
reading sequence.

Animations
must reinforce
reading flow.

Never interrupt reading.

------------------------------------------------------------------------------

# 18. ACCEPTANCE CRITERIA

Reading Journey passes only when:

✓ Users understand the report
without technical knowledge.

✓ Users naturally continue scrolling.

✓ Every scroll answers
one new question.

✓ The report feels like
one continuous consultation.

✓ Users never feel lost.

✓ Users never ask
"What should I read next?"

------------------------------------------------------------------------------

# 19. FREEZE

After approval,
this Reading Journey becomes immutable.

Future UI redesigns
may improve aesthetics,

but

must never change
the reading journey defined here.
