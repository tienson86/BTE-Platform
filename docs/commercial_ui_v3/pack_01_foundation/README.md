# 1. PURPOSE

Commercial UI V3 defines the ONLY accepted presentation architecture for
BTE Platform.

After V3 is frozen:

- Cursor SHALL NOT redesign layouts.
- Cursor SHALL NOT invent components.
- Cursor SHALL NOT change hierarchy.
- Cursor SHALL NOT change reading flow.
- Cursor SHALL ONLY implement.

This document becomes the single source of truth for every screen related to
BaZi consultation.

------------------------------------------------------------------------------

# 2. WHAT BTE IS

BTE is NOT:

✗ Dashboard

✗ Admin Panel

✗ BI Analytics Tool

✗ Data Viewer

✗ Spreadsheet

✗ JSON Viewer

✗ Developer Console

BTE IS:

✓ Professional BaZi Consultation Platform

✓ Explainable Analysis Platform

✓ Knowledge-driven Decision Support System

✓ Consultation Report Generator

The experience must resemble reading a professional consulting report,
not operating a management dashboard.

------------------------------------------------------------------------------

# 3. PRODUCT PHILOSOPHY

The customer does not buy data.

The customer buys understanding.

Therefore every screen must answer:

"What does this mean for me?"

before showing

"How was it calculated?"

Facts support conclusions.

Rules support facts.

Knowledge supports rules.

Never reverse this order.

------------------------------------------------------------------------------

# 4. USER EXPERIENCE PRINCIPLE

Reading experience has higher priority than data density.

Understanding has higher priority than visualization.

Consultation has higher priority than calculation.

Hierarchy has higher priority than decoration.

Whitespace has higher priority than borders.

Typography has higher priority than colors.

------------------------------------------------------------------------------

# 5. TARGET EXPERIENCE

The user should feel like reading:

• Premium consulting report

• Financial advisory report

• Medical executive report

• Research document

Never feel like:

• ERP

• CRM

• Admin Portal

• Analytics Dashboard
