# UI-18 Before / After — CASE-0001

Source: Narrative V2 Presentation only. No Narrative, Runtime, Presentation, or Export edits.

Before: UI-14 mobile is a single-column scale of the desktop analysis order (Hero → Interpretation → Action → evidence).

After: Mobile is a decision sequence. Desktop analysis order is unchanged.

## What changed

| Area | Before (UI-14 mobile) | After (UI-18) |
|------|------------------------|---------------|
| Reading goal | Scan the same dashboard | Understand and act in 30–60s |
| Visual order | Overview → Interpretation → Action → structure | Hero / Priority / Executive → Action → Interpretation → Luck → supporting → evidence |
| Disclosure | Full cards | Executive + Action open; interpretation zones and evidence collapsed |
| Hero | Full-width card | First viewport (`70dvh`) with sticky Top Priority |
| Spacing | `--space-5` between cards | `--space-7` section rhythm |
| Navigation | None | Thumb-zone bar: Kế hoạch / Luận giải |
| Tablet | Same order as desktop | Action promoted between Overview and Interpretation |
| Desktop | Analysis hierarchy | Unchanged |

## CASE-0001 still reads the same words

Overview insight, interpretation lead, and action titles are Presentation copy. UI-18 only changes visual order and disclosure chrome.
