# UI-17 Print Grid

- Size: A4 portrait (210 × 297 mm)
- Safe area: Header / Body / Footer
- Margins (Print Design System mid-range):
  - Top 20 mm
  - Right 18 mm
  - Bottom 22 mm
  - Left 18 mm
- No Dashboard grid
- Print-safe width is the A4 content box inside those margins
- Running header occupies the top margin band
- Running footer occupies the bottom margin band
- Cover fills page 1, then `break-after: page`
