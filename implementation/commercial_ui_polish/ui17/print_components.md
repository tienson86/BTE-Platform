# UI-17 Print Components

Print is a consumer of the UI-16 Executive Report. Components wrap existing sections. They do not compose Narrative.

| Component | Role |
|-----------|------|
| PrintCover | Cover as print page 1. Reuses ReportCover fields. |
| PrintHeader | Running header: report title, customer, optional version. |
| PrintFooter | Running footer: Generated by BTE, version, Confidential, page marker. |
| PrintSection | Page-break policy (`break-before`, `keep-together`). |
| PrintCallout | Insight (Executive Summary) and Top Priority only. |
| PrintDivider | Editorial hairline. Not a dashboard border. |
| PrintAppendix | Appendix on a new section plus archive signature. |

Location: `applications/customer_portal/src/screens/executive_report/print/`
